# 教程总览与学习路线

> 这套教程带你从"没装过 JDK"走到"能独立做出并发布一个完整的 NeoForge 1.21.1 模组"。

## 这套教程是什么

这是一套**面向新手的中文 Minecraft 模组开发教程**，基于 NeoForge 1.21.1，配套本站翻译的 NeoForge 官方文档（`/docs/neoforge-1.21.1/`）。

它和官方文档的区别：

| | 官方文档 | 这套教程 |
|---|---|---|
| 定位 | 参考手册，查得到但不好读 | 教学，按学习顺序讲 |
| 假设 | 你熟悉 Java 和模组开发 | 你只会一点点 Java |
| 代码 | 片段式 | 同一套示例工程，可一路复制 |
| 术语 | 直接用 | 第一次出现就解释，附录有词典 |

**不假设你懂的东西**：泛型、Lambda、方法引用 `::`、`Supplier`、Builder 模式、注解、record、Optional、Codec —— 这些普通 Java 教程里往往不讲，但模组代码里到处都是。第二章专门解决这件事。

**假设你懂的东西**：类、方法、变量、`if`/`for`、继承、接口的基本概念。如果这些也陌生，建议先花一周过一遍任意 Java 入门教程的前 8 章，再回来。

## 怎么用这套教程

1. **第一次学**：按 01 → 08 的顺序读，别跳。每一篇都有可运行代码，边读边敲。
2. **卡住了**：先翻 `08-附录/02-常见报错与排错手册.md`，那里有 29 个高频报错的"现象 → 原因 → 解决"。
3. **忘了术语**：翻 `08-附录/01-术语表.md`，66 条，按主题分组。
4. **看到看不懂的写法**：翻 `02-Java补充篇/`，那一章就是为"这行代码每个符号我都认识，连起来不知道在干嘛"准备的。
5. **想查某个 API 的权威说明**：翻配套译文 `/docs/neoforge-1.21.1/`，每篇开头都有原文链接。

## 学习路线

### 阶段一：能跑起来（第 1 周）

| 章节 | 学完能做到 |
|---|---|
| 01-准备篇 | 装好 JDK 和 IDE，生成工程，`gradlew runClient` 进游戏并在 Mods 列表里看到自己的模组 |
| 02-Java补充篇 | 看懂注册代码里 `() -> new Item(...)`、`Block::new`、`new Item.Properties().stacksTo(16)` 这些写法 |

**这个阶段别急着写功能**，先把"环境能跑通 + 代码能看懂"这两件事做掉，后面会顺很多。

### 阶段二：能做出东西（第 2~4 周）

| 章节 | 学完能做到 |
|---|---|
| 03-核心概念篇 | 理解注册表、事件总线、客户端/服务端、资源位置、数据组件 —— 这五个概念是后面一切的地基 |
| 04-内容制作篇 | 做出带纹理的物品、方块、方块实体、创造标签页、工具盔甲、食物与状态效果 |
| 05-资源与数据篇 | 独立写模型/纹理/语言文件，会用数据生成，会写配方、战利品表、标签、进度 |

### 阶段三：能做完整的模组（第 5~8 周）

| 章节 | 学完能做到 |
|---|---|
| 06-进阶篇 | 做 GUI（菜单+界面）、用能力接入漏斗管道、存数据、写 Codec、做客户端/服务端网络同步、加世界生成、写附魔、必要时用 Mixin |

### 阶段四：能发布（第 9 周起）

| 章节 | 学完能做到 |
|---|---|
| 07-实战篇 | 独立完成一个含矿物、材料、功能方块、GUI、附魔、进度的完整模组；知道哪里会拖性能；能打包发布到 CurseForge / Modrinth |
| 08-附录 | 遇到问题能自己查、自己定位 |

## 关于「Java 补充篇」

这一章不是 Java 语法课，也不会从头教你写 `for` 循环。它只解决一件事：

> **你在模组代码里看到这些写法，普通 Java 教程没讲过，所以你不知道它在干什么。**

比如这行注册代码：

```java
public static final DeferredItem<Item> RUBY = ITEMS.register("ruby", () -> new Item(new Item.Properties()));
```

里面至少藏着四个"教程没讲过"的东西：

| 写法 | 是什么 | 看哪篇 |
|---|---|---|
| `DeferredItem<Item>` | 泛型：这个容器里装的是 `Item` | [01-注册代码里的泛型与Supplier](02-Java补充篇/01-注册代码里的泛型与Supplier.md) |
| `() -> new Item(...)` | Lambda，在这里充当 `Supplier`（延迟创建） | 同上 |
| 为什么不能直接 `new` | 注册时序问题 | 同上 |
| `new Item.Properties().xxx()` | Builder 链式调用 | [03-Builder与链式调用](02-Java补充篇/03-Builder与链式调用.md) |

还有 `Block::new` 这种双冒号写法在 [02-双冒号与方法引用](02-Java补充篇/02-双冒号与方法引用.md)，`@Mod` / `@SubscribeEvent` 这类注解在 [04-注解](02-Java补充篇/04-注解-@开头的那些标签.md)。

**建议**：先通读 01 和 03 两篇（它们出现频率最高），其余等实际遇到再回来看，不必一次读完。

## 学习建议

1. **一定要动手**。看懂和写出来是两回事，每篇的「练习」不要跳过。
2. **先跑通，再理解**。第一次见到 `DeferredRegister` 不用全懂，照着抄能跑起来就行，后面章节会反复用到，自然就懂了。
3. **崩溃不是失败，是信息**。学会看 `logs/latest.log` 和 `crash-reports/`，附录 02 讲了怎么读。
4. **不要抄旧教程**。1.20 → 1.21 变化很大（数据组件取代物品 NBT、`ResourceLocation` 构造方式改了），网上大量教程已经过时。判断方法：看代码里有没有 `new ResourceLocation(...)`、`Item.Properties#tab(...)`，有就是旧的。
5. **版本要对齐**。本教程固定为 Minecraft 1.21.1 + NeoForge 21.1.x + Java 21，混用版本是新手最常见的坑。
