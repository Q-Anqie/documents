# 大肥鱼 MC 教程

> 从"没装过 JDK"到"能独立做出并发布一个完整 NeoForge 模组"。

这套教程基于 **Minecraft 1.21.1 + NeoForge 21.1 + Java 21**，共 8 章 46 篇，示例工程固定为 `dafeiyu` / `com.dafeiyu`，代码可一路复制累积成完整模组。

**如果你是新手，从这里开始**：[00-教程总览与学习路线](00-教程总览与学习路线.md)
