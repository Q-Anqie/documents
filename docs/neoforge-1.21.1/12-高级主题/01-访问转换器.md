# 访问转换器（Access Transformer）

访问转换器（Access Transformer，简称 AT）允许放宽可见性，并修改类、方法和字段的 `final` 标记。它使模组作者能够访问和修改那些原本无法访问的、由他人控制的类中的成员。

[规范文档][specs]可在 NeoForged 的 GitHub 上查看。

## 添加 AT

向模组项目添加访问转换器非常简单，只需在 `build.gradle` 中加入一行：

访问转换器必须在 `build.gradle` 中声明。AT 文件可以放在任意位置，只要在编译时被复制到 `resources` 输出目录即可。

```groovy
// In build.gradle:
// This block is where your mappings version is also specified
minecraft {
    accessTransformers {
        file('src/main/resources/META-INF/accesstransformer.cfg')
    }
}
```

默认情况下，NeoForge 会查找 `META-INF/accesstransformer.cfg`。如果 `build.gradle` 将访问转换器指定在其他位置，则需要在 `neoforge.mods.toml` 中定义其位置：

```toml
# In neoforge.mods.toml:
[[accessTransformers]]
## The file is relative to the output directory of the resources, or the root path inside the jar when compiled
## The 'resources' directory represents the root output directory of the resources
file="META-INF/accesstransformer.cfg"
```

此外，可以指定多个 AT 文件，它们将按顺序应用。这对包含多个包的大型模组很有用。

```groovy
// In build.gradle:
minecraft {
    accessTransformers {
        file('src/main/resources/accesstransformer_main.cfg')
        file('src/additions/resources/accesstransformer_additions.cfg')
    }
}
```

```toml
# In neoforge.mods.toml
[[accessTransformers]]
file="accesstransformer_main.cfg"

[[accessTransformers]]
file="accesstransformer_additions.cfg"
```

在添加或修改任何访问转换器之后，必须刷新 Gradle 项目才能使转换生效。

## 访问转换器规范

### 注释

`#` 之后直到行尾的所有文本都将被视为注释，不会被解析。

### 访问修饰符

访问修饰符指定给定目标将被转换为何种新的成员可见性。按可见性从高到低排列：

- `public` - 对其包内和包外的所有类可见
- `protected` - 仅对包内的类和子类可见
- `default` - 仅对包内的类可见
- `private` - 仅对类内部可见

可以在上述修饰符后附加特殊修饰符 `+f` 和 `-f`，分别用于添加或移除 `final` 修饰符。`final` 修饰符会阻止子类化、方法重写或字段修改。

> **危险**
>
> 指令只修改其直接引用的方法；任何重写方法都不会被访问转换。建议确保被转换的方法不存在限制可见性的未转换重写方法，否则会导致 JVM 抛出错误。
>
> 可以安全转换的方法示例包括 `final` 方法（或 `final` 类中的方法）以及 `static` 方法。`private` 方法通常也是安全的；但它们可能在任意子类型中造成意外的重写，因此应进行一些额外的手动验证。

### 目标与指令

#### 类

以类为目标：

```
<access modifier> <fully qualified class name>
```

内部类通过将外部类的全限定名与内部类的名字用 `$` 作为分隔符组合来表示。

#### 字段

以字段为目标：

```
<access modifier> <fully qualified class name> <field name>
```

#### 方法

以方法为目标需要特殊语法来表示方法参数与返回类型：

```
<access modifier> <fully qualified class name> <method name>(<parameter types>)<return type>
```

##### 指定类型

也称为"描述符"：更多技术细节请参见 [Java 虚拟机规范 SE 21 第 4.3.2 与 4.3.3 节][jvmdescriptors]。

- `B` - `byte`，一个有符号字节
- `C` - `char`，UTF-16 中的 Unicode 字符码点
- `D` - `double`，一个双精度浮点值
- `F` - `float`，一个单精度浮点值
- `I` - `integer`，一个 32 位整数
- `J` - `long`，一个 64 位整数
- `S` - `short`，一个有符号短整数
- `Z` - `boolean`，一个 `true` 或 `false` 值
- `[` - 表示数组的一个维度
    - 示例：`[[S` 表示 `short[][]`
- `L<class name>;` - 表示一个引用类型
    - 示例：`Ljava/lang/String;` 表示 `java.lang.String` 引用类型_（注意使用斜杠而不是点号）_
- `(` - 表示一个方法描述符，应在此处提供参数；若无参数则留空
    - 示例：`<method>(I)Z` 表示一个需要一个整数参数并返回布尔值的方法
- `V` - 表示方法不返回任何值，只能用在方法描述符的末尾
    - 示例：`<method>()V` 表示一个没有参数且无返回值的方法

### 示例

```
# Makes public the ByteArrayToKeyFunction interface in Crypt
public net.minecraft.util.Crypt$ByteArrayToKeyFunction

# Makes protected and removes the final modifier from 'random' in MinecraftServer
protected-f net.minecraft.server.MinecraftServer random

# Makes public the 'makeExecutor' method in Util,
# accepting a String and returns an ExecutorService
public net.minecraft.Util makeExecutor(Ljava/lang/String;)Ljava/util/concurrent/ExecutorService;

# Makes public the 'leastMostToIntArray' method in UUIDUtil,
# accepting two longs and returning an int[]
public net.minecraft.core.UUIDUtil leastMostToIntArray(JJ)[I
```
