## 翻译约定

- **代码一律保留原文**：所有 Java / JSON / TOML 代码块（含代码内注释）、类名、方法名、字段名、包名、路径、资源 ID 均未翻译。
- **术语统一**：block→方块、item→物品、block entity→方块实体、loot table→战利品表、data component→数据组件、capability→能力、advancement→进度、enchantment→附魔、damage type→伤害类型 等，完整对照表见 `_WIKI_MAP.md` 与 `_TRANSLATION_GUIDE.md`。
- **MDX 清洗**：原文的 `import`/`export` 语句、`<Tabs>`/`<TabItem>` 组件已移除（标签转为加粗小标题），`:::note` / `:::tip` / `:::warning` / `:::danger` 提示块转为引用块（`> **注意**` 等）。
- **链接改写**：原文相对链接（含文末 `[key]: url` 引用定义）已统一改写为 `https://docs.neoforged.net/docs/1.21.1/...` 绝对地址，可直接跳回原文核对；页内锚点保留英文锚点以对齐原文。
- **Minecraft Wiki 链接**：每篇的页面标题下、以及对应的 `##` 小节标题下，插入了中文 Minecraft Wiki（`zh.minecraft.wiki`）的对应条目，例如「模型」→ [模型](https://zh.minecraft.wiki/w/模型)、「战利品表」→ [战利品表](https://zh.minecraft.wiki/w/战利品表)。仅在确有对应条目时插入，抽象概念（注册表、事件、网络协议等）不强行链接。
- 每篇文件开头带 YAML front matter，记录中文标题、英文原标题、原文 URL 与版本，便于溯源。
