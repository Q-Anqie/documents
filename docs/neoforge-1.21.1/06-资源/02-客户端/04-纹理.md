# 纹理

> 相关 Minecraft Wiki：[纹理](https://zh.minecraft.wiki/w/纹理)

Minecraft 中的所有纹理都是位于命名空间 `textures` 文件夹内的 PNG 文件。不支持 JPG、GIF 及其他图像格式。指向纹理的[资源位置][rl]路径通常相对于 `textures` 文件夹，例如，资源位置 `examplemod:block/example_block` 指向位于 `assets/examplemod/textures/block/example_block.png` 的纹理文件。

纹理通常应为 2 的幂尺寸，例如 16x16 或 32x32。与旧版本不同，现代 Minecraft 原生支持大于 16x16 的方块和物品纹理尺寸。对于非 2 的幂且由你自己渲染的纹理（例如 GUI 背景），请创建一个下一个可用 2 的幂尺寸（通常是 256x256）的空文件，并把你的纹理放在该文件的左上角，让文件其余部分保持空白。然后可以在使用该纹理的代码中设置实际绘制的纹理尺寸。

## 纹理元数据

> 相关 Minecraft Wiki：[纹理](https://zh.minecraft.wiki/w/纹理)

纹理元数据可以在一个与纹理完全同名、并额外带有 `.mcmeta` 后缀的文件中指定。例如，位于 `textures/block/example.png` 的动画纹理需要一个配套的 `textures/block/example.png.mcmeta` 文件。`.mcmeta` 文件具有以下格式（全部可选）：

```json5
{
    // Whether the texture will be blurred if needed. Defaults to false.
    // Currently specified by the codec, but unused otherwise both in the files and in code.
    "blur": true,
    // Whether the texture will be clamped if needed. Defaults to false.
    // Currently specified by the codec, but unused otherwise both in the files and in code.
    "clamp": true,
    "gui": {
        // Specifies how the texture will be scaled if needed. Can be one of these three:
        "scaling": {
            "type": "stretch" // default
        },
        "scaling": {
            "type": "tile",
            "width": 16,
            "height": 16
        },
        "scaling": {
            // Like "tile", but allows specifying the border offsets.
            "type": "nine_slice",
            "width": 16,
            "height": 16,
            // May also be a single int that is used as the value for all four sides.
            "border": {
                "left": 0,
                "top": 0,
                "right": 0,
                "bottom": 0
            }
        }
    },
    // See below.
    "animation": {}
}
```

## 动画纹理

> 相关 Minecraft Wiki：[纹理](https://zh.minecraft.wiki/w/纹理)

Minecraft 原生支持方块和物品的动画纹理。动画纹理由单个纹理文件组成，其中不同的动画阶段彼此上下排列（例如，一个 8 帧的 16x16 动画纹理会表现为一个 16x128 的 PNG 文件）。

要真正实现动画效果而不只是显示为扭曲的纹理，纹理元数据中必须有一个 `animation` 对象。该子对象可以为空，但可以包含以下可选条目：

```json5
{
    "animation": {
        // A custom order in which the frames are played. If omitted, the frames are played top to bottom.
        "frames": [1, 0],
        // How long one frame stays before switching to the next animation stage, in frames. Defaults to 1.
        "frametime": 5,
        // Whether to interpolate between animation stages. Defaults to false.
        "interpolate": true,
        // Width and height of one animation stage. If omitted, uses the texture width for both of these.
        "width": 12,
        "height": 12
    }
}
```
