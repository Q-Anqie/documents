# 内置附魔效果组件

> 相关 Minecraft Wiki：[魔咒](https://zh.minecraft.wiki/w/魔咒)

原版 Minecraft 提供了大量不同类型的附魔效果组件，供[附魔][enchantment]定义使用。本文将逐一说明它们，包括其用法与代码中的定义方式。

## 数值效果组件

_另见 Minecraft Wiki 上的[数值效果组件][Value Effect Components]_

数值效果组件用于修改游戏中某个数值的附魔，由 `EnchantmentValueEffect` 类实现。如果某个值被多个数值效果组件修改（例如被多个附魔修改），它们的效果会全部生效。

数值效果组件可以设置为对其给定的值执行以下任一操作：

- `minecraft:set`：覆盖给定的基于等级的值。
- `minecraft:add`：将指定的基于等级的值加到旧值上。
- `minecraft:multiply`：将指定的基于等级的因子乘以旧值。
- `minecraft:remove_binomial`：按二项分布抽取给定的（基于等级的）概率。若命中，则从值中减去 1。注意许多值实际上是标志位，1 表示完全开启，0 表示完全关闭。
- `minecraft:all_of`：接受一组其他数值效果，并按给定顺序依次应用。

锋利附魔使用数值效果组件 `minecraft:damage` 来实现其效果，如下所示：

**JSON**

```json5
"effects": {
    // The type of this effect component is "minecraft:damage".
    // This means that the effect will modify weapon damage.
    // See below for a list of more effect component types.
    "minecraft:damage": [
        {
            // A value effect that should be applied.
            // In this case, since there's only one, this value effect is just named "effect".
            "effect": {
                // The type of value effect to use. In this case, it is "minecraft:add", so the value (given below) will be added 
                // to the weapon damage value.
                "type": "minecraft:add",

                // The value block. In this case, the value is a LevelBasedValue that starts at 1 and increases by 0.5 every enchantment level.
                "value": {
                    "type": "minecraft:linear",
                    "base": 1.0,
                    "per_level_above_first": 0.5
                }
            }
        }
    ]
}
```

**Datagen**

```java
// Passed into 'effects' in an Enchantment during data generation
// See the Data Generation section of the Enchantments entry to learn more
DataComponentMap.builder().set(
    // Selects the "minecraft:damage" component.
    EnchantmentEffectComponents.DAMAGE,

    // Constructs a list of one conditional AddValue without any requirements.
    List.of(new ConditionalEffect<>(
        new AddValue(LevelBasedValue.perLevel(1.0F, 0.5F)),
        Optional.empty()))
).build()
```

`value` 块内的对象是一个 [LevelBasedValue]，它可用于让数值效果组件随等级改变其效果强度。

`EnchantmentValueEffect#process` 方法可用于按所提供的数值运算调整值，如下所示：

```java
// `valueEffect` is an EnchantmentValueEffect instance.
// `enchantLevel` is an integer representing the level of the enchantment
float baseValue = 1.0;
float modifiedValue = valueEffect.process(enchantLevel, server.random, baseValue);
```

### 原版附魔数值效果组件类型

#### 定义为 `DataComponentType<EnchantmentValueEffect>`

- `minecraft:crossbow_charge_time`：以秒为单位修改该弩的蓄力时间。由快速装填使用。
- `minecraft:trident_spin_attack_strength`：修改三叉戟旋转攻击的"强度"（参见 `TridentItem#releaseUsing`）。由激流使用。

#### 定义为 `DataComponentType<List<ConditionalEffect<EnchantmentValueEffect>>>`

盔甲相关：

- `minecraft:armor_effectiveness`：决定盔甲对该武器的有效性，范围从 0（无保护）到 1（正常保护）。由破甲使用。
- `minecraft:damage_protection`：每"点"伤害减免会使持有该物品时受到的伤害降低 4%，最高减免 80%。由爆炸保护、摔落缓冲、火焰保护、保护、弹射物保护使用。

攻击相关：

- `minecraft:damage`：修改该武器的攻击伤害。由锋利、穿刺、节肢杀手、力量、亡灵杀手使用。
- `minecraft:smash_damage_per_fallen_block`：为锤每下落一格增加伤害。由密度使用。
- `minecraft:knockback`：修改持有该武器时造成的击退量，以游戏单位计。由击退、冲击使用。
- `minecraft:mob_experience`：修改击杀生物获得的经验量。未使用。

耐久相关：

- `minecraft:item_damage`：修改物品受到的耐久损伤。小于 1 的值表示物品受损的概率。由耐久使用。
- `minecraft:repair_with_xp`：使物品通过获得的经验自我修复，并决定其有效程度。由经验修补使用。

弹射物相关：

- `minecraft:ammo_use`：修改使用弓或弩射击时消耗的弹药量。该值会被截断为整数，因此小于 1 的值将导致不消耗弹药。由无限使用。
- `minecraft:projectile_piercing`：修改该武器发射的弹射物可穿透的实体数量。由穿透使用。
- `minecraft:projectile_count`：修改使用该弓射击时生成的弹射物数量。由多重射击使用。
- `minecraft:projectile_spread`：修改弹射物相对发射方向的最大散布角度。由多重射击使用。
- `minecraft:trident_return_acceleration`：使三叉戟返回其主人，并修改返回过程中施加到该三叉戟上的加速度。由忠诚使用。

其他：

- `minecraft:block_experience`：修改破坏方块获得的经验量。由精准采集使用。
- `minecraft:fishing_time_reduction`：使用该钓竿钓鱼时，按给定秒数减少浮漂下沉所需的时间。由饵钓使用。
- `minecraft:fishing_luck_bonus`：修改钓鱼战利品表中使用的[幸运][luck]值。由海之眷顾使用。

#### 定义为 `DataComponentType<List<TargetedConditionalEffect<EnchantmentValueEffect>>>`

- `minecraft:equipment_drops`：修改被该武器击杀的实体掉落装备的概率。由抢夺使用。

## 基于位置的效果组件

_另见：Minecraft Wiki 上的[基于位置的效果组件][Location Based Effect Components]_

> 相关 Minecraft Wiki：[状态效果](https://zh.minecraft.wiki/w/状态效果)

基于位置的效果组件是实现 `EnchantmentLocationBasedEffect` 的组件。这些组件定义了需要知道附魔持有者在世界中位置的行动。它们主要通过两个方法运作：`EnchantmentEntityEffect#onChangedBlock`，在装备被附魔的物品时以及持有者的 `BlockPos` 发生变化时调用；以及 `onDeactivate`，在移除被附魔的物品时调用。

下面是一个示例，它使用 `minecraft:attributes` 基于位置的效果组件类型来改变持有者的实体缩放：

**JSON**

```json5
// The type is "minecraft:attributes" (described below).
// In a nutshell, this applies an attribute modifier.
"minecraft:attributes": [
    {
        // This "amount" block is a LevelBasedValue.
        "amount": {
            "type": "minecraft:linear",
            "base": 1,
            "per_level_above_first": 1
        },

        // Which attribute to modify. In this case, modifies "minecraft:scale"
        "attribute": "minecraft:generic.scale",
        // The unique identifier for this attribute modifier. Should not overlap with others, but doesn't need to be registered.
        "id": "examplemod:enchantment.size_change",
        // What operation to use on the attribute. Can be "add_value", "add_multiplied_base", or "add_multiplied_total".
        "operation": "add_value"
    }
],
```

**Datagen**

```java
// Passed into the effects of an Enchantment during data generation
DataComponentMap.builder().set(
    // Specifies the "minecraft:attributes" component type.
    EnchantmentEffectComponents.ATTRIBUTES,

    // This component takes a list of these EnchantmentAttributeEffect objects.
    List.of(new EnchantmentAttributeEffect(
        ResourceLocation.fromNamespaceAndPath("examplemod", "enchantment.size_change"),
        Attributes.SCALE,
        LevelBasedValue.perLevel(1F, 1F),
        AttributeModifier.Operation.ADD_VALUE
    ))
).build()
```

原版添加了以下基于位置的事件：

- `minecraft:all_of`：按顺序运行一组实体效果。
- `minecraft:apply_mob_effect`：对受影响的生物施加[生物效果][mob effect]。
- `minecraft:attribute`：对附魔持有者施加[属性修饰符][attribute modifier]。
- `minecraft:damage_entity`：对受影响的实体造成伤害。若处于攻击情境，该伤害会与攻击伤害叠加。
- `minecraft:damage_item`：损伤该物品的耐久。
- `minecraft:explode`：召唤一次爆炸。
- `minecraft:ignite`：使实体着火。
- `minecraft:play_sound`：播放指定的声音。
- `minecraft:replace_block`：替换给定偏移处的方块。
- `minecraft:replace_disk`：替换圆盘状的方块区域。
- `minecraft:run_function`：运行指定的[数据包函数][datapack function]。
- `minecraft:set_block_properies`：修改指定方块的状态属性。
- `minecraft:spawn_particles`：生成粒子。
- `minecraft:summon_entity`：召唤一个实体。

### 原版基于位置的效果组件类型

#### 定义为 `DataComponentType<List<ConditionalEffect<EnchantmentLocationBasedEffect>>>`

- `minecraft:location_changed`：当持有者的方块位置发生变化时以及装备该物品时运行基于位置的效果。由冰霜行者、灵魂疾行使用。

#### 定义为 `DataComponentType<List<EnchantmentAttributeEffect>>`

- `minecraft:attributes`：对持有者施加属性修饰符，并在不再装备该附魔物品时移除。

## 实体效果组件

> 相关 Minecraft Wiki：[实体](https://zh.minecraft.wiki/w/实体)

_另见 Minecraft Wiki 上的[实体效果组件][Entity Effect Components]。_

实体效果组件是实现 `EnchantmentEntityEffect` 的组件，而 `EnchantmentEntityEffect` 是 `EnchantmentLocationBasedEffect` 的子类型。它们重写 `EnchantmentLocationBasedEffect#onChangedBlock` 以改为运行 `EnchantmentEntityEffect#apply`；该 `apply` 方法还会根据组件的具体类型在代码库的其他位置被直接调用。这使得效果无需等待持有者的方块位置发生变化即可发生。

所有基于位置的效果组件类型同时也是有效的实体效果组件类型，但 `minecraft:attribute` 除外，它仅注册为基于位置的效果组件。

下面是火焰附加附魔中这样一个组件的 JSON 定义示例：

**JSON**

```json5
// This component's type is "minecraft:post_attack" (see below).
"minecraft:post_attack": [
    {
        // Decides whether the "victim" of the attack, the "attacker", or the "damaging entity" (the projectile if there is one, attacker if not) recieves the effect.
        "affected": "victim",
        
        // Decides which enchantment entity effect to apply.
        "effect": {
            // The type of this effect is "minecraft:ignite".
            "type": "minecraft:ignite",
            // "minecraft:ignite" requires a LevelBasedValue as a duration for how long the entity will be ignited.
            "duration": {
                "type": "minecraft:linear",
                "base": 4.0,
                "per_level_above_first": 4.0
            }
        },

        // Decides who (the "victim", "attacker", or "damaging entity") must have the enchantment for it to take effect.
        "enchanted": "attacker",

        // An optional predicate which controls whether the effect applies.
        "requirements": {
            "condition": "minecraft:damage_source_properties",
            "predicate": {
                "is_direct": true
            }
        }
    }
]
```

**Datagen**

```java
// Passed into the effects of an Enchantment during data generation
DataComponentMap.builder().set(
    // Specifies the "minecraft:post_attack" component type.
    EnchantmentEffectComponents.POST_ATTACK,

    // Defines the data for this component. In this case, a list of one TargetedConditionalEffect.
    List.of(
        new TargetedConditionalEffect<>(

            // Determines the "enchanted" field.
            EnchantmentTarget.ATTACKER,

            // Determines the "affected" field.
            EnchantmentTarget.VICTIM,

            // The enchantment entity effect.
            new Ignite(LevelBasedValue.perLevel(4.0F, 4.0F)),

            // The "requirements" clause. 
            // In this case, the only optional part activated is the isDirect boolean flag.
            Optional.of(
                new DamageSourceCondition(
                    Optional.of(
                        new DamageSourcePredicate(
                            List.of(),
                            Optional.empty(),
                            Optional.empty(),
                            Optional.of(true)
                        )
                    )
                )
            )
        )
    )
).build()
```

这里的实体效果组件是 `minecraft:post_attack`。其效果为 `minecraft:ignite`，由 `Ignite` record 实现。该 record 对 `EnchantmentEntityEffect#apply` 的实现会使目标实体着火。

### 原版附魔实体效果组件类型

#### 定义为 `DataComponentType<List<ConditionalEffect<EnchantmentEntityEffect>>>`

- `minecraft:hit_block`：当实体（例如弹射物）击中方块时运行实体效果。由引雷使用。
- `minecraft:tick`：每个 tick 运行一次实体效果。由灵魂疾行使用。
- `minecraft:projectile_spawned`：当弓或弩生成弹射物实体后运行实体效果。由火矢使用。

#### 定义为 `DataComponentType<List<TargetedConditionalEffect<EnchantmentEntityEffect>>>`

- `minecraft:post_attack`：当攻击对实体造成伤害后运行实体效果。由节肢杀手、引雷、火焰附加、荆棘、风爆使用。

关于其中每一项的更多细节，请查看[相关的 Minecraft Wiki 页面][relevant minecraft wiki page]。

## 其他原版附魔组件类型

> 相关 Minecraft Wiki：[魔咒](https://zh.minecraft.wiki/w/魔咒)

#### 定义为 `DataComponentType<List<ConditionalEffect<DamageImmunity>>>`

- `minecraft:damage_immunity`：对指定伤害类型施加免疫。由冰霜行者使用。

#### 定义为 `DataComponentType<Unit>`

- `minecraft:prevent_equipment_drop`：防止该物品在玩家死亡时掉落。由消失诅咒使用。
- `minecraft:prevent_armor_change`：防止该物品从盔甲槽位中被卸下。由绑定诅咒使用。

#### 定义为 `DataComponentType<List<CrossbowItem.ChargingSounds>>`

- `minecraft:crossbow_charge_sounds`：决定为弩蓄力时发生的声音事件。每个条目代表附魔的一个等级。

#### 定义为 `DataComponentType<List<Holder<SoundEvent>>>`

- `minecraft:trident_sound`：决定使用三叉戟时发生的声音事件。每个条目代表附魔的一个等级。
