# 🎯 后端面试复习指引（基于本套 26 篇文档）

> 配套《devjava-zh》17 板块中文文档使用。按**面试命中率**排序，优先攻克最高频板块。

---

## 一、三步复习法（建议节奏）

1. **扫读**：每篇先看「核心速查表」快速建立框架（10 分钟/篇）。
2. **精读代码**：把示例代码复制到 IDE 跑一遍，自己改参数验证（重点板块）。
3. **自测**：看文末「面试高频」问题，盖住答案口述——讲不出来就是没掌握。

## 三、高频原题自测（自测时一题答 3 点以上才算过）

### 集合
1. **ArrayList 和 LinkedList 区别？为何现代选 ArrayList？**（底层结构 + CPU 缓存/指针追逐）
2. **HashMap 底层原理？Java 8 起有何变化？**（数组+链表+红黑树、负载因子 0.75、扩容、hash 扰动）
3. **HashMap 线程安全吗？并发场景用什么？**（ConcurrentHashMap vs Hashtable vs Collections.synchronizedMap）
4. **为什么 Map 键要不可变且重写 equals/hashCode？**
5. **List.of() 返回的集合有何特性？**（不可变、禁 null）
6. **为何不用 Stack？栈/队列首选什么？**

### Stream
7. **Stream 的中间操作和终结操作区别？**（惰性求值）
8. **collect(Collectors.toList()) vs toSet() vs groupingBy()？**
9. **并行流 parallelStream 有何风险？**（线程安全、顺序、性能开销）
10. **Optional 怎么用？如何避免 NPE？**（orElse/orElseGet/map/flatMap）

### 面向对象
11. **接口和抽象类怎么选？**（is-a vs can-do、多继承、默认方法）
12. **重载和重写的区别？**
13. **四种访问控制级别及可见范围？**
14. **static 和 final 关键字作用？**（类变量、不可变、常量）

### 注解与反射
15. **@Override/@Deprecated/@SuppressWarnings 作用？**
16. **什么是元注解？常见的有哪些？**（@Target/@Retention/@Documented/@Inherited）
17. **反射怎么获取类信息？**（Class.forName/类名.class/getClass）
18. **Spring 依赖注入如何用反射实现？**（@Autowired + Field.setAccessible）

## 四、推荐开发环境配置（跑示例代码）

```bash
# JDK 建议用 21+（支持虚拟线程、Records 正式版）
java -version   # 应显示 21 或更高

# 官方示例多为单文件，可直接编译运行
java 01-集合框架深入.java        # Java 11+ 支持单文件源码运行
javac 01-集合框架深入.java        # 或编译后 java 类名
```

> **注意**：文档示例是标准 Java 写法，直接复制到 IDE（IntelliJ IDEA / Eclipse）即可运行。若版本低于 Java 21，虚拟线程示例需 JDK 19+ 且加 `--enable-preview`（19/20），21 起正式无需预览。

## 五、求职加分建议

- **讲原理胜过背语法**：面试官更看重"为什么"，比如 ArrayList 选型背后的 CPU 缓存原理，比列 API 印象深得多。
- **结合框架讲**：注解+反射是 Spring/MyBatis 的基石，讲 DI 时能扯到反射，是明显的加分点。
- **手写代码练习**：挑集合/Stream 各 2 道题手写（如手写 HashMap 简化版、用 Stream 分组统计），面试常考手写。
