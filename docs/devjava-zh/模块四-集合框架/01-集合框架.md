# 集合框架（Collections Framework）

> 来源：Oracle 官方 [Dev.java 教程](https://dev.java/learn/) →《Collections Framework》
> 忠实翻译，保留全部代码示例与官方配图。

**集合框架是一个统一的架构，用于表示和操作集合（一组对象）。** 它包含：

- **接口（Interfaces）**：集合的抽象数据类型。接口允许独立于其具体表示来操作集合。
- **实现（Implementations）**：接口的具体实现，即可复用的数据结构。
- **算法（Algorithms）**：对实现接口的对象执行有用计算的方法，如排序、搜索。

## 一、集合框架的组织结构

[集合接口层次结构](../assets/images/collections-framework/01_interfaces-hierarchy.png)

集合框架的核心是**接口**。它提供了所有集合的抽象数据类型：

| 接口 | 说明 |
|------|------|
| `Collection` | 集合层次结构的根接口。一组称为元素的独立对象（通常不允许重复）。 |
| `List` | 有序集合（序列）。允许重复元素。可通过整数索引访问。 |
| `Set` | 不包含重复元素的集合。 |
| `SortedSet` | 按升序排列元素的 Set。 |
| `NavigableSet` | 支持导航操作（如查找最接近目标的元素）的扩展 SortedSet。 |
| `Queue` | 用于处理前保存元素的集合。通常是 FIFO（先进先出）。 |
| `Deque` | 支持在两端插入、删除元素的线性集合。 |
| `Map` | 将键（key）映射到值（value）的对象。键不能重复。 |
| `SortedMap` | 按键升序排列的 Map。 |
| `NavigableMap` | 支持导航操作的扩展 SortedMap。 |

**两类核心集合**：

- **`Collection`**：**单元素集合**（每个元素独立存在），包括 `List`、`Set`、`Queue`、`Deque`。
- **`Map`**：**键值对集合**（每个元素由键和值组成），包括 `Map`、`SortedMap`、`NavigableMap`。

## 二、`Collection` 接口

`Collection` 接口是集合框架中处理**单元素集合**（如 `Set`、`List`、`Deque`）的最基本接口。它定义了所有单元素集合通用的操作。

### 关键方法

**批量操作（bulk operations）** 一次操作整个集合：

| 方法 | 说明 |
|------|------|
| `boolean containsAll(Collection<?> c)` | 是否包含 c 中所有元素 |
| `boolean addAll(Collection<? extends E> c)` | 添加 c 中所有元素 |
| `boolean removeAll(Collection<?> c)` | 移除与 c 相同的所有元素 |
| `boolean retainAll(Collection<?> c)` | 仅保留与 c 相同的元素 |
| `void clear()` | 移除所有元素 |

### 遍历（Iteration）

有三种遍历集合的方式：

**① 使用增强 for 循环（for-each）**：

```java
for (Object o : collection) {
    System.out.println(o);
}
```

**② 使用 `Iterator`**：

```java
for (Iterator<String> i = collection.iterator(); i.hasNext(); ) {
    String element = i.next();
    System.out.println(element);
}
```

**③ 使用 `forEach` 方法 + lambda**：

```java
collection.forEach(System.out::println);
```

**注意**：在遍历时**不能通过 `Iterator` 的 `remove()` 之外的方式修改集合结构**（如直接 `collection.remove(...)`），否则会抛出 `ConcurrentModificationException`。安全删除：

```java
Iterator<String> i = collection.iterator();
while (i.hasNext()) {
    if (i.next().equals("target")) {
        i.remove();   // 用迭代器删除，安全
    }
}
```

## 三、`List` 接口（列表）

**`List` 是有序集合（序列），允许重复元素，允许 `null`，支持整数索引访问。** 列表通常比集合（Set）允许更多元素，因为 List 允许重复，而 Set 不允许。

### List 特有方法

| 方法 | 说明 |
|------|------|
| `E get(int index)` | 按索引取元素 |
| `E set(int index, E element)` | 替换指定位置的元素 |
| `void add(int index, E element)` | 在指定位置插入 |
| `E remove(int index)` | 移除指定位置的元素 |
| `int indexOf(Object o)` | 查找元素第一次出现的位置 |
| `List<E> subList(int from, int to)` | 返回子列表视图 |
| `void sort(Comparator<? super E> c)` | 排序 |

### List 实现

**`ArrayList`** —— 动态数组实现。**随机访问快，中间插入/删除慢**（需移动元素）。

```java
List<String> list = new ArrayList<>();
list.add("apple");
list.add("banana");
list.get(0);   // apple
```

[ArrayList 插入示意](../assets/images/collections-framework/05_Inserting-ArrayList.png)

**`LinkedList`** —— 链表实现。**头部/尾部插入删除快，随机访问慢**。

[链表结构](../assets/images/collections-framework/04_Linked-list-structure.png)

**`Vector`** —— 同步的 ArrayList（较古老，一般用 `Collections.synchronizedList` 替代）。

### ArrayList vs LinkedList 选择

| 场景 | 推荐 |
|------|------|
| 频繁按索引随机访问 | `ArrayList` |
| 频繁在头部/中间插入删除 | `LinkedList` |
| 大量追加、遍历 | `ArrayList` |

## 四、`Set` 接口（集合）

**`Set` 是不包含重复元素的集合。** 数学意义上的集合。`Set` 接口继承了 `Collection`，没有引入新方法，只是对方法语义加了限制。

**实现**：

| 实现 | 特点 |
|------|------|
| `HashSet` | 哈希表，无序，O(1) 基本操作。最常用。 |
| `LinkedHashSet` | 哈希表 + 链表，**保持插入顺序**。 |
| `TreeSet` | 红黑树，**按值排序**，O(log n) 操作。 |

```java
Set<String> set = new HashSet<>();
set.add("apple");
set.add("banana");
set.add("apple");   // 重复，被忽略
System.out.println(set);   // [apple, banana]

Set<Integer> sorted = new TreeSet<>();
sorted.add(5);
sorted.add(1);
sorted.add(3);
System.out.println(sorted);   // [1, 3, 5] 升序
```

**`Set` 去重的关键**：元素必须正确实现 `equals()` 与 `hashCode()` 方法（如自定义对象作为元素时）。

## 五、`Map` 接口（映射）

**`Map` 是映射键到值的对象。键不能重复，每个键最多映射到一个值。** 与 `Collection` 不同，`Map` 处理的是**键值对**，不是单个元素。

### Map 核心方法

| 方法 | 说明 |
|------|------|
| `V put(K key, V value)` | 放入键值对 |
| `V get(Object key)` | 按键取值 |
| `boolean containsKey(Object key)` | 是否含键 |
| `boolean containsValue(Object value)` | 是否含值 |
| `V remove(Object key)` | 移除键值对 |
| `Set<K> keySet()` | 返回键的集合视图 |
| `Collection<V> values()` | 返回值的集合视图 |
| `Set<Map.Entry<K,V>> entrySet()` | 返回键值对的集合视图 |

### Map 实现

| 实现 | 特点 |
|------|------|
| `HashMap` | 哈希表，无序，O(1) 基本操作。最常用。 |
| `LinkedHashMap` | 保持插入顺序（或访问顺序）。 |
| `TreeMap` | 按键排序（红黑树）。 |
| `Hashtable` | 同步（较古老）。 |

```java
Map<String, Integer> map = new HashMap<>();
map.put("apple", 1);
map.put("banana", 2);
System.out.println(map.get("apple"));   // 1
System.out.println(map.containsKey("banana"));   // true

// 遍历键值对
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " -> " + entry.getValue());
}
```

### Map 与 Lambda（常用技巧）

```java
Map<String, Integer> map = new HashMap<>();
map.put("apple", 5);

// getOrDefault：键存在返回值，否则返回默认
System.out.println(map.getOrDefault("banana", 0));   // 0

// putIfAbsent：键不存在才放入
map.putIfAbsent("apple", 10);
System.out.println(map.get("apple"));   // 5

// computeIfAbsent：键不存在时用函数计算并放入
map.computeIfAbsent("pear", k -> k.length());
System.out.println(map.get("pear"));   // 4
```

### 选择映射键（Choosing Keys）

作为 Map 键的对象**必须正确实现 `equals()` 和 `hashCode()`**，且最好**不可变**（如 `String`、包装类型、`LocalDate`）。可变对象作键可能导致值无法被正确检索（因 hashCode 变化）。

## 六、栈与队列（Stacks & Queues）

**`Deque`（双端队列）** 接口支持在两端的插入、删除和检查操作。`ArrayDeque` 是其通用实现。

**作为栈使用**（后进先出 LIFO）：

```java
Deque<String> stack = new ArrayDeque<>();
stack.push("first");
stack.push("second");
stack.push("third");
System.out.println(stack.pop());   // third（后进先出）
```

**作为队列使用**（先进先出 FIFO）：

```java
Deque<String> queue = new ArrayDeque<>();
queue.offer("first");
queue.offer("second");
queue.offer("third");
System.out.println(queue.poll());   // first（先进先出）
```

**注意**：官方推荐用 `Deque` / `ArrayDeque` 替代旧的 `Stack` 类（`Stack` 继承自 `Vector`，有同步开销且 API 设计不佳）。

## 七、工厂方法（Factory Methods）

Java 9 起，集合接口提供了**不可变集合工厂方法**，快速创建只读集合：

```java
List<String> list = List.of("a", "b", "c");
Set<String> set = Set.of("a", "b", "c");
Map<String, Integer> map = Map.of("apple", 1, "banana", 2);
```

**特性**：

- 返回**不可变**集合（任何修改操作都抛 `UnsupportedOperationException`）。
- 不允许 `null` 元素/键值。
- 元素顺序不保证（Set/Map）。
- 比手写 `Collections.unmodifiableList` 更简洁紧凑。

```java
// Map 创建超过 10 对键值对用 Map.ofEntries
Map<String, Integer> big = Map.ofEntries(
    Map.entry("a", 1),
    Map.entry("b", 2),
    Map.entry("c", 3)
);
```

## 八、集合的算法（Algorithms）

集合框架提供的算法都是**静态方法**，作用于任意实现相应接口的集合，**且返回新集合而非就地修改**（除了 `sort`、`shuffle` 等少数）。它们位于 `java.util.Collections` 类中。

**常用算法**：

| 方法 | 说明 |
|------|------|
| `Collections.sort(list)` | 排序（自然序） |
| `Collections.sort(list, comparator)` | 自定义排序 |
| `Collections.reverse(list)` | 反转 |
| `Collections.shuffle(list)` | 打乱 |
| `Collections.min(coll)` / `max(coll)` | 最值 |
| `Collections.binarySearch(list, key)` | 二分查找 |
| `Collections.copy(dest, src)` | 复制 |
| `Collections.fill(list, obj)` | 填充 |
| `Collections.nCopies(n, obj)` | 创建 n 个副本的不可变列表 |

```java
List<Integer> nums = new ArrayList<>(List.of(3, 1, 2));
Collections.sort(nums);              // [1, 2, 3]
Collections.reverse(nums);           // [3, 2, 1]
System.out.println(Collections.max(nums));   // 3
```

## 九、迭代与修改的坑（重点）

**① `ConcurrentModificationException`**：在遍历时通过集合自身方法（`add`/`remove`）修改结构，会抛此异常。安全做法用 `Iterator.remove()` 或 `removeIf`：

```java
list.removeIf(s -> s.length() > 3);   // Java 8+ 推荐
```

**② 用 `Map` 的 `entrySet` 遍历并删除**：

```java
map.entrySet().removeIf(e -> e.getValue() < 0);
```

## 核心速查表

| 接口 | 语义 | 常用实现 | 特点 |
|------|------|---------|------|
| `List` | 有序、可重复、可索引 | `ArrayList`、`LinkedList` | ArrayList 随机访问快 |
| `Set` | 不重复 | `HashSet`、`TreeSet` | TreeSet 有序，HashSet 无序 |
| `Queue` | 先进先出 | `ArrayDeque` | FIFO |
| `Deque` | 双端操作 | `ArrayDeque` | 可做栈/队列 |
| `Map` | 键值对 | `HashMap`、`TreeMap` | TreeMap 按键排序 |

> **面试高频**：`ArrayList` vs `LinkedList`（随机访问 vs 头尾操作）、`HashMap` vs `TreeMap`（哈希 vs 有序树）、`HashSet` 去重依赖 `equals`/`hashCode`、遍历时删除用 `removeIf` 防 `ConcurrentModificationException`、`List.of()`/`Map.of()` 不可变。
