## 一、变量（Variables）

在上一节你已经知道：**对象把它的状态存储在字段（fields）中**。本节回答几个常见疑问：
- 字段的命名规则和约定是什么？
- 除了 `int`，还有哪些数据类型？
- 字段声明时必须初始化吗？
- 如果没有显式初始化，字段会获得默认值吗？

在 Java 中，「字段」和「变量」这两个词都会用到，这是新手常困惑的地方。Java 语言定义了**以下四类变量**：

### 1. 实例变量（Instance Variables，即非静态字段）
对象把各自的独立状态存在「非静态字段」里，即**没有 `static` 关键字**声明的字段。非静态字段也叫实例变量，因为它们的值对类的每个实例（即每个对象）是唯一的：一辆自行车的 `currentSpeed`（当前速度）与另一辆无关。

### 2. 类变量（Class Variables，即静态字段）
类变量是**用 `static` 修饰符**声明的字段，它告诉编译器：**无论类被实例化多少次，这个变量只存在一份拷贝**。例如定义某种自行车齿轮数的字段可以标记为 `static`，因为概念上所有实例的齿轮数相同。

```java
static int numGears = 6;
```

上面的代码创建了一个静态字段。还可以加上 `final` 关键字，表示齿轮数永远不会改变。

### 3. 局部变量（Local Variables）
与方法把临时状态存在字段里类似，方法经常把**临时状态存在局部变量**中。声明局部变量的语法与声明字段类似（例如 `int count = 0;`）。没有专门的关键字表示「局部变量」，它完全由**声明的位置**决定——即方法的一对大括号 `{ }` 之间。因此，局部变量**只对声明它的方法可见**，类中其他部分无法访问它。

### 4. 参数（Parameters）
你已经见过参数例子（如 `Bicycle` 类、`main` 方法）。回顾一下 `main` 方法的签名：

```java
public static void main(String[] args)
```

这里的 `args` 就是该方法的参数。要记住：**参数永远归类为「变量」而不是「字段」**。这一规则同样适用于其他接收参数的构造（如构造器、异常处理器），后续会学到。

> **术语约定**：后续内容中——
> - 若泛指「字段」（不含局部变量和参数），只说「字段」；
> - 若指「以上全部」，只说「变量」；
> - 需区分时，会用具体术语（静态字段、局部变量等）。
> 你可能还会看到「成员（member）」一词：一个类型的字段、方法和嵌套类型统称为它的**成员**。

## 二、变量命名规则与约定

每种语言都有自己的命名规则和约定，Java 也不例外。要点如下：

### 命名规则
- **变量名区分大小写**。
- 变量名可以是任何**合法标识符**——无限长度的 Unicode 字母和数字序列，**必须以字母、`$` 或 `_` 开头**。但约定是**始终以字母开头**，不用 `$` 或 `_`。
- 按约定，`$` 符号**完全不被使用**（有些自动生成的代码会含 `$`，但你自己的变量名应避免）。
- `_` 开头虽然技术上合法，但**不推荐**。
- **不允许空白字符**。
- 后续字符可以是字母、数字、`$` 或 `_`。
- **用完整单词而非晦涩缩写**，让代码自我说明。例如 `cadence`、`speed`、`gear` 远比 `s`、`c`、`g` 直观。
- 变量名**不能是关键字或保留字**。

### 命名约定
- 单单词：**全小写**。
- 多单词：**首单词小写，后续单词首字母大写**（驼峰式）。例如 `gearRatio`、`currentGear`。
- **常量**：全大写，单词间用 `_` 分隔。例如 `static final int NUM_GEARS = 6`。约定上 `_` 只用于此，别处不用。

## 三、基本数据类型（Primitive Types）

Java 是**静态类型**语言，所有变量必须**先声明后使用**。声明要说明变量的类型和名称：

```java
int gear = 1;
```

这告诉程序：存在一个名为 `gear` 的字段，存数值，初始值为 `1`。变量的数据类型决定了它可包含的值，以及可对其执行的操作。

**基本类型**是语言预定义的，由保留关键字命名，基本类型的值不与其他基本类型共享状态。Java 支持 **8 种基本数据类型**：

| 类型 | 说明 | 取值范围 |
|------|------|---------|
| `byte` | 8 位有符号二进制补码整数 | -128 ~ 127（含） |
| `short` | 16 位有符号二进制补码整数 | -32,768 ~ 32,767（含） |
| `int` | 32 位有符号二进制补码整数 | -2³¹ ~ 2³¹-1 |
| `long` | 64 位二进制补码整数 | -2⁶³ ~ 2⁶³-1 |
| `float` | 32 位 IEEE 754 单精度浮点 | 范围见 Java 语言规范 |
| `double` | 64 位 IEEE 754 双精度浮点 | 范围见 Java 语言规范 |
| `boolean` | 只有 `true` / `false` 两个值 | — |
| `char` | 16 位 Unicode 字符 | `\u0000`(0) ~ `\uffff`(65,535 含) |

### 各种类型要点

- **`byte`**：8 位有符号补码整数，范围 -128~127。适合**节省大数组内存**（内存节省真正重要时），或在范围限制能帮助澄清代码时替代 `int`。
- **`short`**：16 位有符号补码整数，范围 -32,768~32,767。与大数组内存节省场景同 `byte`。
- **`int`**：默认整数类型，32 位有符号补码整数，范围 -2³¹ ~ 2³¹-1。
- **`long`**：64 位补码整数，范围 -2⁶³ ~ 2⁶³-1。
- **`float`**：32 位单精度浮点。**绝不要用于精确值（如货币）**，需要精确值请用 `java.math.BigDecimal` 类。大数组浮点内存节省时可替代 `double`。
- **`double`**：64 位双精度浮点，是**默认的浮点选择**。同样**不要用于货币精确值**。
- **`boolean`**：只有 `true`/`false`，用于简单标志位（true/false 条件），约占 1 位信息，但「大小」没有精确定义。
- **`char`**：单个 16 位 Unicode 字符，范围 `\u0000`(0) ~ `\uffff`(65,535 含)。

### Java SE 8+ 的无符号整数
- 可用 `int` 表示**无符号 32 位整数**（0 ~ 2³²-1），用 `Integer` 类操作。`Integer` 类新增了 `compareUnsigned()` 等静态方法支持无符号运算。
- 可用 `long` 表示**无符号 64 位整数**（0 ~ 2⁶⁴-1），需要比 `int` 更宽范围时使用。`Long` 类也有 `compareUnsigned()`、`divideUnsigned()` 等方法。

### String（字符串）
除了 8 种基本类型，Java 还通过 `java.lang.String` 类**专门支持字符串**。用双引号包裹字符串会自动创建新的 `String` 对象：

```java
String greeting = "Hello World!";
```

`String` 对象是**不可变（immutable）**的——一旦创建，值不能改变。`String` 技术上不是基本类型，但鉴于语言对它的特殊支持，你可能会把它当基本类型看待。

## 四、用默认值初始化变量

字段声明时**不一定要赋值**。未初始化的字段编译器会赋一个**合理的默认值**（通常是 0 或 null，取决于数据类型）。但依赖默认值通常被认为是**不良编程风格**。

各数据类型的字段默认值：

| 数据类型 | 默认值（字段） |
|---------|--------------|
| `byte` | 0 |
| `short` | 0 |
| `int` | 0 |
| `long` | 0L |
| `float` | 0.0f |
| `double` | 0.0d |
| `char` | `\u0000` |
| `String`（或任意对象） | `null` |
| `boolean` | `false` |

> **注意局部变量不同**：编译器**永远不会**给未初始化的局部变量赋默认值。如果无法在声明处初始化，务必在使用前赋值，否则**编译报错**。访问未初始化的局部变量是编译时错误。

## 五、用字面量（Literals）创建值

你可能注意到：初始化基本类型变量时**不用 `new` 关键字**。基本类型是语言内建的特殊类型，不是类创建的对象。

**字面量**是固定值的源代码表示，直接在代码中写出，无需计算。如下可以把字面量赋给基本类型变量：

```java
boolean result = true;
char capitalC = 'C';
byte b = 100;
int i = 100000;
```

### 整数（Integer）字面量
- 以 `L` 或 `l` 结尾 → `long` 类型；否则为 `int`。**推荐大写 `L`**，因为小写 `l` 易与数字 `1` 混淆。
- `byte`、`short`、`int`、`long` 的值可由 `int` 字面量创建；超出 `int` 范围的 `long` 值由 `long` 字面量创建。
- 支持三种进制：
  - **十进制**：基数 10（0~9），日常使用；
  - **十六进制**：基数 16（0~9、A~F），前缀 `0x`；
  - **二进制**：基数 2（0、1），前缀 `0b`（Java SE 7+）。

```java
// 十进制、十六进制、二进制示例
int decVal = 26;
int hexVal = 0x1a;
int binVal = 0b11010;
```

### 浮点（Floating-Point）字面量
- 以 `F`/`f` 结尾 → `float`；否则为 `double`，可选的 `D`/`d` 结尾（默认，按约定省略）。
- 可用 `E`/`e` 表示科学计数法。

```java
double d1 = 123.4;
double d2 = 1.234e2;
float f1 = 123.4f;
```

### 字符和字符串字面量
- `char` 和 `String` 字面量可包含任何 Unicode（UTF-16）字符。编辑器允许时可直接写，否则用 `\u0108`（带抑扬符的 C）、`"S\u00ED Se\u00F1or"` 这类 Unicode 转义。
- **`char` 用单引号，`String` 用双引号**。
- Unicode 转义序列也可用在程序其他地方（如字段名），不只限字面量。
- 特殊转义序列：`\b`（退格）、`\t`（制表）、`\n`（换行）、`\f`（换页）、`\r`（回车）、`\"`（双引号）、`\'`（单引号）、`\\`（反斜杠）。

### null 字面量与类字面量
- `null` 可作为任何**引用类型**的值，可赋给除基本类型外的任何变量。`null` 通常用作「某对象不可用」的标记。
- **类字面量**：由类型名加 `.class` 构成，如 `String.class`，指代代表该类型本身的 `Class` 类型对象。

### 数字字面量中的下划线
Java SE 7 起，可以在数字字面量**数字之间任意位置**插入下划线 `_`，用来分组提高可读性：

```java
long creditCardNumber = 1234_5678_9012_3456L;
long socialSecurityNumber = 999_99_9999L;
double pi = 3.141_592_653;
```

**下划线只能放在数字之间**，不能放在：
- 数字开头或结尾；
- 浮点字面量的小数点旁边；
- 在 `F` 或 `L` 后缀之前；
- 需要一串数字的位置。

**合法与非法示例**：

```java
// 合法
int x1 = 5_2;              // 52
int x2 = 5_______2;        // 52
int x3 = 0x5_2;            // 0x52
int x4 = 0_52;             // 052（八进制）
int x5 = 0x5_2;            // 0x52
// 非法
// int x = _52;             // 不能以 _ 开头（标识符下划线问题）
// int x = 52_;             // 不能以 _ 结尾
// int x = 52_;             // 数字后
// float f = 1_2.3_4f;      // 合法，但后缀前不能有 _
```

## 本节小结
- Java 同时使用「字段」和「变量」两个术语。实例变量（非静态字段）对每个实例唯一；类变量（静态字段）无论实例化多少次只有一份；局部变量存方法内的临时状态；参数是给方法提供额外信息的变量，局部变量和参数永远归类为「变量」。
- 命名变量要遵守规则和约定。
- 8 种基本数据类型：`byte`、`short`、`int`、`long`、`float`、`double`、`boolean`、`char`。`java.lang.String` 类表示字符串。
- 编译器为上述类型的**字段**赋合理默认值；**局部变量**从不赋默认值。
- 字面量是固定值的源代码表示。数组是容纳固定数量单类型值的容器对象，长度在创建时确定，创建后固定。
