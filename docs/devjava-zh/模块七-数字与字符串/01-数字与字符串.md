# 数字与字符串（Numbers and Strings）

> 来源：Oracle 官方 [Dev.java 教程](https://dev.java/learn/) →《Numbers and Strings》
> 忠实翻译，保留全部代码示例与官方配图。

本模块讲解 Java 中**数字（Number）与字符串（String）**两个最常用的数据类型，包括：数字的表示与格式化、自动装箱（autoboxing）、字符与字符串的常用操作、`StringBuilder` 的构造与使用。

---

## 一、数字（Numbers）

### 数字类（Number 的子类）

Java 提供了一组**包装类（wrapper class）**，把基本类型包装成对象，放在 `java.lang` 包中，都是 `Number` 类的子类：

| 基本类型 | 包装类 | 继承层次 |
|---------|--------|---------|
| `byte` | `Byte` | `Number` |
| `short` | `Short` | `Number` |
| `int` | `Integer` | `Number` |
| `long` | `Long` | `Number` |
| `float` | `Float` | `Number` |
| `double` | `Double` | `Number` |
| `char` | `Character` | —（不继承 Number） |
| `boolean` | `Boolean` | —（不继承 Number） |

[Number 类层次](../assets/images/numbers-strings/01_numbers.png)

**为什么需要包装类？**

1. **集合（如 `ArrayList`）不能存储基本类型**，需要包装类对象。
2. 泛型类型参数不能用基本类型，只能用引用类型（`List<Integer>` 而非 `List<int>`）。
3. 包装类提供**转换和实用方法**（如 `Integer.parseInt`、`Integer.toString`）。

### 自动装箱与拆箱（Autoboxing and Unboxing）

**自动装箱（autoboxing）**：编译器自动把基本类型转换为对应的包装类对象。

**自动拆箱（unboxing）**：编译器自动把包装类对象转换为对应的基本类型。

```java
// 自动装箱：int -> Integer
Integer a = 42;                 // 等价于 Integer.valueOf(42)

// 自动拆箱：Integer -> int
int b = a;                      // 等价于 a.intValue()

// 在集合中使用
List<Integer> list = new ArrayList<>();
list.add(1);                    // 自动装箱 int -> Integer
int value = list.get(0);        // 自动拆箱 Integer -> int
```

**注意**：拆箱可能抛出 `NullPointerException`（若包装类为 `null`）。

### 数字格式化（Formatting Numeric Print Output）

用 `String.format` 或 `System.out.printf`（两者相同格式）。

```java
int i = 461012;
System.out.format("The value of i is: %d%n", i);    // %d 整数，%n 换行

double d = 3.14159;
System.out.printf("%.2f%n", d);    // 保留 2 位小数：3.14

System.out.printf("%1$d %2$s%n", 42, "hello");   // 位置参数：42 hello
```

**常用格式说明符**：

| 说明符 | 类型 | 示例 |
|--------|------|------|
| `%d` | 十进制整数 | `%d` → `461012` |
| `%f` | 浮点数 | `%.2f` → `3.14` |
| `%s` | 字符串 | `%s` → `hello` |
| `%c` | 字符 | `%c` → `a` |
| `%b` | 布尔 | `%b` → `true` |
| `%e` | 科学计数法 | `%e` → `3.141593e+00` |
| `%n` | 换行 | 平台相关换行符 |
| `%x` | 十六进制整数 | `%x` → `707e` |

### 数字的解析与转换

```java
// 字符串转数字
int i = Integer.parseInt("123");
double d = Double.parseDouble("3.14");

// 数字转字符串
String s1 = Integer.toString(123);
String s2 = String.valueOf(456);
```

### 数字类的实用方法

```java
Integer.max(10, 20);        // 20
Integer.min(10, 20);        // 10
Integer.sum(10, 20);        // 30
Integer.compare(10, 20);    // -1
Math.max(3, 7);             // 7
Math.round(3.6);            // 4
Math.floor(3.7);            // 3.0
Math.ceil(3.2);             // 4.0
Math.random();              // 0.0~1.0 随机
```

## 二、字符（Characters）

`char` 是单个 16 位 Unicode 字符，`Character` 类提供操作字符的静态方法。

```java
char c = 'a';
System.out.println(Character.isLetter(c));      // true
System.out.println(Character.isDigit('5'));     // true
System.out.println(Character.isUpperCase('A')); // true
System.out.println(Character.toUpperCase('a')); // A
```

[Character 方法示例](../assets/images/numbers-strings/02_chars.png)

**常用 `Character` 静态方法**：

| 方法 | 说明 |
|------|------|
| `isLetter(char)` | 是否字母 |
| `isDigit(char)` | 是否数字 |
| `isWhitespace(char)` | 是否空白 |
| `isUpperCase(char)` / `isLowerCase(char)` | 是否大写/小写 |
| `toUpperCase(char)` / `toLowerCase(char)` | 转大写/小写 |

## 三、字符串（Strings）

**`String` 表示字符序列，是 Java 中最常用的类之一。** 字符串对象**不可变（immutable）**——一旦创建，其值不能改变。

### 创建字符串

```java
String greeting = "Hello world";    // 字面量
String s = new String("Hello");      // 用构造器（不推荐，除非需要）
```

**关键：字符串池（String pool）**。字面量字符串存储在常量池中，相同内容的字面量引用同一对象：

```java
String a = "hello";
String b = "hello";
System.out.println(a == b);        // true（同一对象，字符串池）
String c = new String("hello");
System.out.println(a == c);        // false（不同对象）
System.out.println(a.equals(c));   // true（内容相等）
```

**比较字符串用 `equals()`，不要用 `==`！**

### 常用 String 方法

| 方法 | 说明 | 示例结果 |
|------|------|---------|
| `length()` | 长度 | `"hello".length()` → 5 |
| `charAt(int)` | 指定下标字符 | `"hello".charAt(1)` → 'e' |
| `substring(int, int)` | 截取子串 | `"hello".substring(1,3)` → "el" |
| `indexOf(String)` | 子串第一次出现位置 | `"hello".indexOf("l")` → 2 |
| `toUpperCase()` / `toLowerCase()` | 大小写转换 | `"Hi".toUpperCase()` → "HI" |
| `trim()` | 去首尾空白 | `"  hi  ".trim()` → "hi" |
| `equals(String)` | 内容比较 | `"a".equals("a")` → true |
| `equalsIgnoreCase(String)` | 忽略大小写比较 | `"A".equalsIgnoreCase("a")` → true |
| `startsWith(String)` / `endsWith(String)` | 前后缀判断 | `"hello".startsWith("he")` → true |
| `contains(CharSequence)` | 是否包含 | `"hello".contains("ell")` → true |
| `replace(char, char)` | 替换字符 | `"hello".replace('l','L')` → "heLLo" |
| `split(String)` | 分割 | `"a,b".split(",")` → ["a","b"] |
| `concat(String)` | 拼接 | `"a".concat("b")` → "ab" |

[String 子串操作](../assets/images/numbers-strings/03_substring.png)

### 字符串拼接

```java
// 用 + 拼接
String s = "Hello, " + "world";    // "Hello, world"

// 用 concat
String s2 = "Hello".concat(" world");

// 用 StringBuilder（循环拼接时效率最高）
```

## 四、StringBuilder（可变字符串）

**`StringBuilder` 是可变的字符序列**，用于频繁拼接/修改字符串的场合。相比 `String` 的不可变性，`StringBuilder` 修改时**不创建新对象**，效率更高。

[StringBuilder 结构](../assets/images/numbers-strings/04_stringbuilder.png)

### 为什么用 StringBuilder？

`String` 不可变，每次 `+` 拼接都创建新对象。在循环中大量拼接时，用 `StringBuilder` 避免创建大量临时对象：

```java
// 低效：循环拼接 String，创建大量中间对象
String result = "";
for (int i = 0; i < 1000; i++) {
    result += i;   // 每次创建新 String
}

// 高效：用 StringBuilder 追加
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}
String result = sb.toString();
```

### StringBuilder 常用方法

| 方法 | 说明 |
|------|------|
| `append(x)` | 追加任意类型 |
| `insert(int offset, x)` | 在指定位置插入 |
| `delete(int start, int end)` | 删除子串 |
| `replace(int start, int end, String)` | 替换子串 |
| `reverse()` | 反转 |
| `toString()` | 转为 String |
| `length()` | 长度 |
| `charAt(int)` | 取字符 |

```java
StringBuilder sb = new StringBuilder("Hello");
sb.append(" World");           // "Hello World"
sb.insert(5, ",");             // "Hello, World"
sb.reverse();                  // "dlroW ,olleH"
System.out.println(sb.toString());
```

### String vs StringBuilder

| 特性 | `String` | `StringBuilder` |
|------|----------|-----------------|
| 可变性 | 不可变 | 可变 |
| 线程安全 | 安全（不可变） | 不安全 |
| 使用场景 | 固定/少量拼接 | 频繁拼接/修改 |
| 效率 | 拼接创建新对象，低 | 原地修改，高 |

> **注**：`StringBuffer` 是线程安全的 `StringBuilder`（加了同步锁），但性能更低，现代单线程场景优先用 `StringBuilder`。

## 核心速查表

| 主题 | 关键点 |
|------|--------|
| 包装类 | 基本类型转对象，`Integer`/`Double` 等，Number 子类 |
| 自动装箱拆箱 | 编译期自动 int↔Integer，拆箱可能抛 NPE |
| 数字格式化 | `String.format` / `System.out.printf`，`%d` `%f` `%s` |
| 数字转换 | `Integer.parseInt` / `Integer.toString` |
| 字符 | `Character` 类，`isLetter`/`isDigit` 等静态方法 |
| String 不可变 | 内容不变，比较用 `equals()` 不用 `==`，字符串池 |
| String 常用方法 | `substring`/`indexOf`/`split`/`replace`/`trim` |
| StringBuilder | 可变、高效拼接，`append`/`insert`/`reverse` |
| String vs SB | 不可变 vs 可变；SB 适合循环/频繁拼接 |

> **面试高频**：`String` 不可变原因（线程安全、字符串池、hashCode 缓存）、`String` vs `StringBuilder` vs `StringBuffer`、字符串比较 `==` vs `equals`、自动装箱/拆箱及缓存（`Integer` 缓存 -128~127）。
