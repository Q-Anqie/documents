# 类与对象深入（Classes and Objects）

> 来源：Oracle 官方 [Dev.java 教程](https://dev.java/learn/) →《Classes and Objects》
> 忠实还原全部子主题：类定义、方法、构造器、调用方法与构造器、创建与使用对象、点运算符/this/访问控制、嵌套类、枚举、何时用嵌套/局部/匿名类/Lambda。面向对象底层细节，后端面试基础。

## 一、创建类（Creating Classes）

类定义的语法，`class` 关键字 + 类名 + 字段 + 方法：

```java
public class Bicycle {
    // 字段（成员变量）
    int cadence = 0;
    int speed = 0;
    int gear = 1;

    // 构造器
    Bicycle(int startCadence, int startSpeed, int startGear) {
        cadence = startCadence;
        speed = startSpeed;
        gear = startGear;
    }

    // 方法
    void changeCadence(int newValue) { cadence = newValue; }
    void applyBrake(int decrement) { speed -= decrement; }
    void speedUp(int increment) { speed += increment; }
}
```

> **要点**：类定义（成员变量/方法/构造器）本身不创建对象，只描述"蓝图"。字段默认有初值（数值 0、引用 null、boolean false）。

---

## 二、定义方法（Defining Methods）

方法的签名由**返回类型、方法名、参数列表**组成（Java 语言中，方法签名不含返回类型）：

```java
public int getSpeed() {
    return speed;
}

void changeCadence(int newValue) {   // void 表示无返回值
    cadence = newValue;
}
```

- **重载（overloading）**：同名方法，不同参数列表（编译器区分）。
- **重写（overriding）**：子类重新实现父类方法（需相同签名，可加 `@Override`）。

```java
public class MountainBike extends Bicycle {
    @Override
    void speedUp(int increment) {        // 重写父类方法
        speed += increment * 2;
    }
}
```

## 三、为类提供构造器（Providing Constructors）

构造器与类同名、无返回类型，用于初始化对象：

```java
public class Bicycle {
    int cadence, speed, gear;

    // 默认构造器（若未写任何构造器，编译器自动提供无参构造器）
    Bicycle() {
        gear = 1;
    }

    // 带参构造器
    Bicycle(int startCadence, int startSpeed, int startGear) {
        cadence = startCadence;
        speed = startSpeed;
        gear = startGear;
    }
}
```

> **关键点**：一旦你**定义了带参构造器，编译器就不再提供默认无参构造器**——需要无参构造时要显式写出。这是常见坑。

**构造器重载 + `this()` 链式调用**：

```java
public class Bicycle {
    int cadence, speed, gear;
    Bicycle() { this(0, 0, 1); }             // 调用带参构造器
    Bicycle(int c, int s, int g) {
        cadence = c; speed = s; gear = g;
    }
}
```

## 四、调用方法与构造器（Calling Methods and Constructors）

方法调用时，**参数按值传递（pass-by-value）**：

```java
// 基本类型：传值副本，方法内修改不影响原变量
int x = 5;
changeValue(x);        // 外部 x 仍是 5

// 引用类型：传引用的副本（指向同一对象），方法内可修改对象内容
StringBuilder sb = new StringBuilder("a");
modify(sb);            // sb 被修改为 "ab"
```

```java
void changeValue(int n) { n = 100; }
void modify(StringBuilder s) { s.append("b"); }
```

> **面试高频**：Java 是**值传递**（pass-by-value），但引用类型的"值"是引用本身——方法内重新赋值引用不影响外部，但修改对象内容会影响外部。这是最经典的面试题。

## 五、创建与使用对象（Creating and Using Objects）

用 `new` + 构造器创建对象，用**点运算符 `.`** 访问字段和方法：

```java
// 1. 声明引用变量
Bicycle myBike;

// 2. 实例化对象（new 分配内存 + 调用构造器）
myBike = new Bicycle(0, 0, 1);

// 3. 使用对象（点运算符访问字段和方法）
myBike.speedUp(10);
int sp = myBike.speed;

// 一步到位的写法
Bicycle other = new Bicycle(0, 0, 2);
other.changeGear(3);
```

> **要点**：`new` 返回一个对象引用；对象在堆上分配，引用变量在栈上。没有引用的对象会被垃圾回收（GC）。

## 六、更多类知识（More on Classes）

### 6.1 点运算符（dot operator）

`.` 用于访问对象/类的成员：`对象.字段`、`对象.方法()`、`类.静态成员`。

```java
bike.speed = 5;          // 访问实例字段
bike.speedUp(10);        // 调用实例方法
Math.max(1, 2);          // 调用静态方法（类名.）
```

### 6.2 this 关键字

`this` 引用当前对象，用于区分字段与局部变量（阴影）、链式调用、构造器委托：

```java
public class Bicycle {
    int speed;
    void setSpeed(int speed) {
        this.speed = speed;     // this.speed 是字段，speed 是参数
    }
    Bicycle getThis() { return this; }   // 返回当前对象
}
```

### 6.3 访问控制（Access Control）

| 修饰符 | 本类 | 同包 | 子类 | 任意 |
|--------|:----:|:----:|:----:|:----:|
| `private` | ✓ | ✗ | ✗ | ✗ |
| `default`（无修饰） | ✓ | ✓ | ✗ | ✗ |
| `protected` | ✓ | ✓ | ✓ | ✗ |
| `public` | ✓ | ✓ | ✓ | ✓ |

> **面试高频**：四种访问控制级别及可见范围（记忆口诀：private 本类、default 同包、protected 同包+子类、public 全公开）。类本身只能是 public 或 default。

## 七、嵌套类（Nested Classes）

**嵌套类**：定义在另一个类内部的类。分两类：

- **静态嵌套类（static nested class）**：用 `static`，不依赖外部类实例。
- **内部类（inner class）**：非静态，持有外部类实例引用。

```java
public class Outer {
    private int x = 10;

    // 静态嵌套类
    static class StaticNested {
        void show() { System.out.println("静态嵌套类"); }
    }

    // 内部类（非静态）
    class Inner {
        void show() {
            System.out.println("内部类，可访问外部 x = " + x);  // 可访问外部私有成员
        }
    }
}

// 使用
Outer.StaticNested sn = new Outer.StaticNested();  // 静态嵌套类
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();             // 内部类（依赖外部实例）
```

> **面试高频**：静态嵌套类 vs 内部类的区别（静态不依赖外部实例、内部类持有外部引用、内部类可访问外部私有成员）。

## 八、枚举（Enums）

枚举定义类型安全的**固定常量集合**，隐式继承 `java.lang.Enum`：

```java
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

// 使用
Day day = Day.MONDAY;
System.out.println(day.name());    // "MONDAY"
System.out.println(day.ordinal()); // 0（索引）

// 枚举可带字段、方法、构造器（受限）
public enum Planet {
    EARTH(5.976e+24), MARS(6.421e+23);   // 构造器带参
    private final double mass;
    Planet(double mass) { this.mass = mass; }
    public double getMass() { return mass; }
}
```

> **面试高频**：枚举是**单例安全**的（天然满足单例模式）、可作 `switch` 条件、可作 Map 键（天然不可变+正确 equals/hashCode）、可实现接口。

## 九、何时用嵌套类 / 局部类 / 匿名类 / Lambda？

这是官方专门一节的实践指导：

| 类型 | 定义位置 | 用途 | 特点 |
|------|---------|------|------|
| **静态嵌套类** | 类内（static） | 逻辑上属于外部类但独立 | 不依赖外部实例，最常见 |
| **内部类** | 类内（非静态） | 需要访问外部实例成员 | 持有外部引用 |
| **局部类** | 方法体内 | 方法内的临时类 | 局部作用域 |
| **匿名类** | 表达式内 | 一次性实现的接口/类 | 无类名，实现单个接口 |
| **Lambda** | 表达式（Java 8+） | **替代匿名类的函数式场景** | 更简洁，只能用于函数式接口 |

**官方建议**：
- **能用 Lambda 就用 Lambda**——比匿名类简洁得多。
- **匿名类**仅当 Lambda 不适用时（实现多个方法、需要 `this` 指向自身等）。
- **静态嵌套类**适合与外部类逻辑相关但无需其实例的场景。
- **局部类**用于方法内临时逻辑，极少用。

```java
// 匿名类（传统写法，功能上被 Lambda 取代）
Runnable r1 = new Runnable() {
    @Override public void run() { System.out.println("匿名类"); }
};

// Lambda（更简洁）
Runnable r2 = () -> System.out.println("Lambda");
```

> **面试高频**：Lambda 与匿名类的区别（Lambda 更简洁、无独立 `this`、仅函数式接口；匿名类可有字段/多个方法）、函数式接口（单抽象方法）。

## 核心速查表

| 主题 | 关键点 | 要点 |
|------|--------|------|
| 类定义 | `class` + 字段 + 方法 + 构造器 | 蓝图，不创建对象 |
| 方法 | 签名 = 名+参数列表（不含返回类型） | 重载 vs 重写 |
| 构造器 | 与类同名、无返回类型 | 定义带参后默认无参构造消失（坑） |
| 传值 | 值传递（pass-by-value） | 引用副本 vs 对象内容修改 |
| 对象创建 | `new` + 点运算符 | 堆分配，引用在栈 |
| this | 区分字段/参数、链式、构造器委托 | |
| 访问控制 | private/default/protected/public | 四级别可见范围 |
| 嵌套类 | 静态嵌套 vs 内部类 | 内部类持外部引用 |
| 枚举 | 固定常量集，隐式继承 Enum | 单例、可 switch、可做 Map 键 |
| 类类型选择 | 静态嵌套/局部/匿名/Lambda | 优先 Lambda |
