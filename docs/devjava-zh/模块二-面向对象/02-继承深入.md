# 继承（Inheritance）深入：方法覆盖、多态与 super

> 来源：Oracle 官方 [Dev.java 教程](https://dev.java/learn/) →《Inheritance》模块
> 忠实翻译，保留全部代码示例与官方配图。

在前面的章节里，你已多次见到「继承」这个词。在 Java 语言中，**类可以从其他类派生，从而继承那些类的字段和方法。**

## 一、基本定义

- **子类（subclass）**：从另一个类派生的类（也称派生类、扩展类或子类）。
- **超类（superclass）**：被子类派生的类（也称基类或父类）。
- **单继承（single inheritance）**：除了没有超类的 `Object`，每个类都**有且仅有一个直接超类**。
- 在没有任何显式超类的情况下，每个类都**隐式是 `Object` 的子类**。
- 类可以从派生类再派生，层层递进，最终追溯到最顶层的 `Object`。这样的类被称为**从继承链上所有类（直到 `Object`）延续下来的后代**。

**继承的思想简单而强大**：当你想创建一个新类，且已有某个类包含你想要的代码时，可以从现有类派生你的新类。这样就能**复用现有类的字段和方法，而不必自己编写（和调试！）**。

> 子类继承超类的所有成员（字段、方法和嵌套类）。**构造器不是成员**，所以不被子类继承，但子类可以调用超类的构造器。

## 二、继承示例

下面是「类与对象」一节中给出的 `Bicycle` 类的一种可能实现：

```java
public class Bicycle {
    public int cadence;
    public int gear;
    public int speed;

    public Bicycle(int startCadence, int startSpeed, int startGear) {
        gear = startGear;
        cadence = startCadence;
        speed = startSpeed;
    }

    public void setCadence(int newValue) {
        cadence = newValue;
    }
    public void setGear(int newValue) {
        gear = newValue;
    }
    public void applyBrake(int decrement) {
        speed -= decrement;
    }
    public void speedUp(int increment) {
        speed += increment;
    }
}
```

一个作为 `Bicycle` 子类的 `MountainBike` 类声明可能如下：

```java
public class MountainBike extends Bicycle {

    public int seatHeight;

    public MountainBike(int startHeight, int startCadence,
                        int startSpeed, int startGear) {
        super(startCadence, startSpeed, startGear);
        seatHeight = startHeight;
    }

    public void setHeight(int newValue) {
        seatHeight = newValue;
    }
}
```

`MountainBike` 继承 `Bicycle` 的所有字段和方法，并新增 `seatHeight` 字段和设置它的方法。**除了构造器，它相当于你从头编写了一个全新的 `MountainBike` 类**，有四个字段和五个方法。但你并不需要做全部工作。如果 `Bicycle` 类的方法很复杂、调试花了大量时间，这个优势就尤其宝贵。

## 三、子类里能做什么

子类继承父类**所有的 public 和 protected 成员**，无论子类在哪个包中。如果子类与父类在**同一个包**，还继承父类的**包私有（package-private）成员**。你可以按原样使用继承来的成员，替换它们、隐藏它们，或用新成员补充它们：

- 继承的字段可以直接使用，就像其他字段一样。
- 可以在子类声明与超类同名的字段，从而**隐藏**它（不推荐）。
- 可以在子类声明超类没有的新字段。
- 继承的方法可以直接按原样使用。
- 可以在子类编写与超类**同签名**的新实例方法，从而**覆盖（override）**它。
- 可以在子类编写与超类**同签名**的新静态方法，从而**隐藏**它。
- 可以声明超类没有的新方法。
- 可以编写调用超类构造器的子类构造器（隐式或使用 `super` 关键字）。

## 四、超类的私有成员

**子类不继承父类的私有成员。** 但如果超类有访问其私有字段的 public 或 protected 方法，子类也能使用这些方法。

> 嵌套类可以访问其外层类的**所有**私有成员——字段和方法。因此，被子类继承的 public/protected 嵌套类，能**间接**访问超类的所有私有成员。

## 五、对象类型转换（Casting Objects）

我们已经看到，对象的数据类型就是它被实例化时所属的类。例如，写：

```java
MountainBike myBike = new MountainBike(...);
```

`myBike` 的类型就是 `MountainBike`。

`MountainBike` 从 `Bicycle` 和 `Object` 延续而来。因此，**一个 `MountainBike` 既是 `Bicycle` 也是 `Object`**，凡是要用 `Bicycle` 或 `Object` 对象的地方都能使用它。

**反向不一定成立**：一个 `Bicycle` 可能是 `MountainBike`，但不一定是。同理，一个 `Object` 可能是 `Bicycle` 或 `MountainBike`，但不一定是。

**类型转换**是指把一种类型的对象用作另一种类型（在继承和实现允许的对象之间）。例如：

```java
Object obj = new MountainBike(...);
```

`obj` 既是 `Object` 也是 `MountainBike`（直到 `obj` 被赋值为另一个非 `MountainBike` 的对象为止）。这叫**隐式转换（implicit casting）**。

反之，如果我们写：

```java
MountainBike myBike = obj;   // 编译错误
```

会得到编译错误，因为编译器不知道 `obj` 是 `MountainBike`。但我们可以通过**显式转换（explicit casting）**告诉编译器我们承诺把 `MountainBike` 赋给 `obj`：

```java
MountainBike myBike = (MountainBike) obj;
```

这个转换插入一个运行时检查，确认 `obj` 确实被赋了 `MountainBike`，编译器才能安全地假定 `obj` 是 `MountainBike`。如果运行时 `obj` 不是 `MountainBike`，会抛出异常。

> **提示**：你可以用 `instanceof` 运算符对某对象的类型做逻辑测试。这能帮你避免因不当转换导致的运行时错误：
>
> ```java
> if (obj instanceof MountainBike) {
>     MountainBike myBike = (MountainBike) obj;
> }
> ```
>
> 这里 `instanceof` 验证 `obj` 指向 `MountainBike`，这样我们就能放心转换，知道不会抛运行时异常。

## 六、多重继承：状态、实现与类型

类与接口之间一个显著区别是：**类可以有字段，接口不能**。此外，你可以实例化类来创建对象，而接口不能。

**Java 语言不允许你扩展多个类**，原因之一就是要避免**状态的多重继承**（从多个类继承字段的能力）带来的问题。例如，假设你能定义一个继承多个类的新类，实例化它创建对象时，该对象会从所有超类继承字段。如果不同超类的方法或构造器实例化了同一个字段怎么办？哪个方法或构造器优先？**因为接口不包含字段，所以你不用担心状态多重继承带来的问题。**

**实现的多重继承**是从多个类继承方法定义的能力。这类多重继承会产生问题，如名称冲突和歧义。支持此类多重继承的编译器，在遇到含同名方法的超类时，有时无法确定该访问或调用哪个成员或方法。此外，程序员可能不经意地给超类添加新方法而引入名称冲突。

> **默认方法（default method）引入了实现多重继承的一种形式**。一个类可以实现多个接口，而这些接口可能含有同名的默认方法。Java 编译器提供一些规则来确定某个特定类使用哪个默认方法。

Java 语言**支持类型（type）的多重继承**，即一个类实现多个接口的能力。**一个对象可以有多个类型**：它自己类的类型，以及它实现的所有接口的类型。这意味着如果某个变量被声明为某接口类型，它的值可以引用任何从实现该接口的类实例化的对象——这会在「接口作为类型」一节讨论。

与实现的多重继承一样，一个类可以继承它扩展的接口中定义（作为 `default` 或 `static` 方法）的不同实现。这种情况下，编译器或用户必须决定使用哪一个。

## 七、方法覆盖与隐藏（Overriding and Hiding）

### 实例方法覆盖

子类中实例方法若与超类方法**相同签名（相同名称、参数类型与数量、返回类型）**，则该实例方法**覆盖**超类方法。覆盖方法的返回类型可以是对被覆盖返回类型的子类型（协变返回）。

被覆盖的方法通过 `super` 关键字从子类调用：

```java
public class Superclass {
    public void printMethod() {
        System.out.println("Printed in Superclass.");
    }
}

public class Subclass extends Superclass {
    // 覆盖超类方法
    @Override
    public void printMethod() {
        super.printMethod();          // 调用超类版本
        System.out.println("Printed in Subclass.");
    }

    public static void main(String[] args) {
        Subclass s = new Subclass();
        s.printMethod();
    }
}
```

### 静态方法隐藏

子类中静态方法与超类方法同签名，则**隐藏**超类静态方法（而非覆盖）。区分「覆盖实例方法」与「隐藏静态方法」非常重要，它们机制不同。

### `@Override` 注解

用 `@Override` 注解标注方法，编译器会校验它确实覆盖了超类方法——有助于防止拼写错误导致的「以为覆盖了实际没覆盖」。

## 八、多态（Polymorphism）

字典里多态的定义是指生物学中的一种原理：一个生物或物种可以有多种不同形态或阶段。这个原理同样适用于面向对象编程和 Java 语言。**子类可以定义自己独有的行为，同时共享父类的部分功能。**

多态可以通过对 `Bicycle` 类稍作修改来演示。例如，可以给类加一个 `printDescription()` 方法，显示实例中当前存储的所有数据：

```java
public class Bicycle {
    public int cadence;
    public int gear;
    public int speed;

    public Bicycle(int startCadence, int startSpeed, int startGear) {
        gear = startGear; cadence = startCadence; speed = startSpeed;
    }

    public void setCadence(int newValue) { cadence = newValue; }
    public void setGear(int newValue) { gear = newValue; }
    public void applyBrake(int decrement) { speed -= decrement; }
    public void speedUp(int increment) { speed += increment; }

    public void printDescription() {
        System.out.println("\nBike is in gear " + gear
            + " with a cadence of " + cadence
            + " and travelling at a speed of " + speed + ".");
    }
}
```

为演示 Java 的多态特性，用 `MountainBike` 和 `RoadBike` 类扩展 `Bicycle`。给 `MountainBike` 加一个 `suspension` 字段——一个字符串值，表示自行车是否有前减震器（`Front`），或前后都有（`Dual`）。下面是更新后的类：

```java
public class MountainBike extends Bicycle {
    private String suspension;

    public MountainBike(int startCadence, int startSpeed, int startGear,
                        String suspensionType) {
        super(startCadence, startSpeed, startGear);
        this.suspension = suspensionType;
    }

    public String getSuspension() { return this.suspension; }

    public void setSuspension(String suspensionType) {
        this.suspension = suspensionType;
    }

    // 覆盖 printDescription()，除原有信息外还输出减震器数据
    @Override
    public void printDescription() {
        super.printDescription();
        System.out.println("The MountainBike has a " +
            getSuspension() + " suspension.");
    }
}
```

注意被覆盖的 `printDescription()` 方法：除了之前的信息，还把关于减震器的额外数据加进输出。

接下来创建 `RoadBike` 类。因为公路车或竞赛车轮胎很细，加一个属性跟踪轮胎宽度：

```java
public class RoadBike extends Bicycle {
    private int tireWidth;

    public RoadBike(int startCadence, int startSpeed, int startGear,
                    int newTireWidth) {
        super(startCadence, startSpeed, startGear);
        this.tireWidth = newTireWidth;
    }

    public int getTireWidth() { return this.tireWidth; }

    public void setTireWidth(int newTireWidth) {
        this.tireWidth = newTireWidth;
    }

    @Override
    public void printDescription() {
        super.printDescription();
        System.out.println("The RoadBike has " + getTireWidth() +
            " MM tires.");
    }
}
```

注意：这次再次覆盖了 `printDescription()`，显示轮胎宽度信息。

**总结**：有三个类 `Bicycle`、`MountainBike`、`RoadBike`。两个子类都覆盖 `printDescription()` 方法并打印各自独特的信息。

下面是一个测试程序，创建三个 `Bicycle` 变量，每个变量被赋值给三个自行车类之一，然后打印每个变量：

```java
public class TestBikes {
    public static void main(String[] args) {
        Bicycle bike01, bike02, bike03;

        bike01 = new Bicycle(20, 10, 1);
        bike02 = new MountainBike(20, 10, 5, "Dual");
        bike03 = new RoadBike(40, 20, 8, 23);

        bike01.printDescription();
        bike02.printDescription();
        bike03.printDescription();
    }
}
```

测试程序输出如下：

```
Bike is in gear 1 with a cadence of 20 and travelling at a speed of 10.
The MountainBike has a Dual suspension.
Bike is in gear 5 with a cadence of 20 and travelling at a speed of 10.
The RoadBike has 23 MM tires.
```

**Java 虚拟机（JVM）会为每个变量引用的对象调用适当的方法**，而不是调用由变量类型定义的方法。这个行为被称为**虚方法调用（virtual method invocation）**，体现了 Java 语言重要的多态特性。

## 九、隐藏字段（Hiding Fields）

在类内部，与超类同名的字段会**隐藏**超类的字段，即使它们类型不同。在子类内部，超类的字段**不能通过其简单名称引用**，必须通过 `super` 访问。一般而言，**我们不推荐隐藏字段，因为它让代码难以阅读**。

## 十、使用 super 关键字

### 访问超类成员

如果你的方法覆盖了某个超类方法，可以用 `super` 关键字调用被覆盖的方法。也可以用它引用隐藏字段（虽然不推荐隐藏字段）。考虑这个 `Superclass` 类：

```java
public class Superclass {
    public void printMethod() {
        System.out.println("Printed in Superclass.");
    }
}
```

下面是覆盖 `printMethod()` 的子类 `Subclass`：

```java
public class Subclass extends Superclass {
    @Override
    public void printMethod() {
        super.printMethod();
        System.out.println("Printed in Subclass.");
    }

    public static void main(String[] args) {
        Subclass s = new Subclass();
        s.printMethod();
    }
}
```

在 `Subclass` 内部，简单名称 `printMethod()` 指在 `Subclass` 中声明的那个（覆盖了 `Superclass` 中的）。所以要引用从 `Superclass` 继承的 `printMethod()`，`Subclass` 必须如所示使用限定名 `super`。编译执行 `Subclass` 打印：

```
Printed in Superclass.
Printed in Subclass.
```

### 子类构造器

下面的例子说明如何用 `super` 调用超类构造器。回顾 `Bicycle` 示例，`MountainBike` 是 `Bicycle` 的子类。下面是调用超类构造器、然后追加自己初始化代码的 `MountainBike`（子类）构造器：

```java
public MountainBike(int startHeight, int startCadence,
                    int startSpeed, int startGear) {
    super(startCadence, startSpeed, startGear);   // 必须是第一条语句
    seatHeight = startHeight;
}
```

**调用超类构造器必须是子类构造器中的第一条语句**（Java 25 之前；Java 25 起允许在该调用前执行代码）。

调用超类构造器的语法是：

```java
super();
super(parameter list);
```

`super()` 调用超类的无参构造器；`super(参数列表)` 调用参数列表匹配的超类构造器。

> **注**：如果构造器没有显式调用超类构造器，Java 编译器会自动插入对超类**无参构造器**的调用。如果超类没有无参构造器，就会得到编译错误。`Object` 有这样的构造器，所以如果 `Object` 是唯一超类，就没有问题。
>
> 如果子类构造器（显式或隐式）调用了超类的构造器，你可能会想：会不会有一条完整的构造器调用链，一直回溯到 `Object` 的构造器？**确实如此。这被称为构造器链（constructor chaining）**，当类继承链很长时你要意识到它。

## 十一、编写 final 类与方法

你可以把一个类的一部分或全部方法声明为 `final`。在方法声明中用 `final` 关键字，表示**该方法不能被子类覆盖**。`Object` 类就是这样——它的若干方法是 `final`。

如果某方法有不应被更改的实现，且对对象的**一致状态**至关重要，你可能想把它设为 final。例如，你可能想把 `ChessAlgorithm` 类的 `getFirstPlayer()` 方法设为 final：

```java
public class ChessAlgorithm {
    enum ChessPlayer { WHITE, BLACK }
    public final ChessPlayer getFirstPlayer() {
        return ChessPlayer.WHITE;
    }
}
```

**从构造器调用的方法通常应声明为 final。** 如果构造器调用一个非 final 方法，子类可能重新定义该方法，导致令人惊讶或不理想的结果。

> 注意：你也可以把**整个类**声明为 final。被声明为 final 的类**不能被子类化**。这在创建不可变类（如 `String` 类）时尤其有用。

## 核心要点速查

| 主题 | 关键点 |
|------|--------|
| 单继承 | 一个类只有一个直接超类（`Object` 例外） |
| 子类能力 | 覆盖实例方法、隐藏静态方法/字段、新增成员、调用超类构造器 |
| 私有成员 | 子类不继承，但可通过 public/protected 访问器间接使用 |
| 类型转换 | 向上隐式安全；向下需显式 + `instanceof` 检查 |
| 多重继承 | 允许类型多重继承（多接口）；不允许状态/实现多重继承（多类） |
| 多态 | JVM 按对象实际类型调用方法（虚方法调用），而非变量声明类型 |
| super | 调超类构造器（须首句）或引用被覆盖的方法/隐藏字段 |
| final | 方法不可覆盖；类不可被继承；从构造器调用的方法应设为 final |
