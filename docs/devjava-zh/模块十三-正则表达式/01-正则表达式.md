# 正则表达式（Regular Expressions）

> 来源：Oracle 官方 [Dev.java 教程](https://dev.java/learn/) →《Regular Expressions》
> 聚焦 `java.util.regex` 包核心：`Pattern`、`Matcher`、`PatternSyntaxException`。后端高频考点：参数校验、日志匹配、文本提取。

`java.util.regex` 包提供三类核心类：

| 类 | 作用 |
|----|------|
| `Pattern` | 编译后的正则表达式对象（pattern） |
| `Matcher` | 解释 pattern 并对输入字符串执行匹配操作的引擎 |
| `PatternSyntaxException` | 正则表达式语法错误时抛出的异常 |

> **面试高频**：`Pattern.compile()` 与 `String.matches()` 的区别、`find()` vs `matches()` vs `lookingAt()`、`Matcher` 的 `group()`、正则引擎回溯。

---

## 一、引入（Introduction）

字符串字面量里的反斜杠 `\` 需要转义，所以正则表达式里 `\d`（数字）要写成 `"\\d"`。**代码里建议用双反斜杠**，或 `Pattern.quote()` 包裹要按字面匹配的部分。

---

## 二、测试工具（Test Harness）

快速测试一个正则表达式的标准写法：

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;

public class RegexTest {
    public static void main(String[] args) {
        String regex = "\\d+";            // 正则：一个或多个数字
        String input = "abc123def456";
        Pattern pattern = Pattern.compile(regex);
        Matcher matcher = pattern.matcher(input);
        while (matcher.find()) {
            System.out.println("匹配到: " + matcher.group());
        }
    }
}
// 输出：
// 匹配到: 123
// 匹配到: 456
```

## 三、字符串字面量（String Literals）

**反斜杠转义规则**——`\` 在字符串里是转义字符，因此正则的 `\d` 在 Java 源码里必须写 `"\\d"`：

| 正则意图 | Java 字符串写法 |
|---------|---------------|
| 数字 `\d` | `"\\d"` |
| 单词边界 `\b` | `"\\b"` |
| 反斜杠 `\\` | `"\\\\"` |

---

## 四、字符类（Character Classes）

| 写法 | 匹配 |
|------|------|
| `[abc]` | a、b 或 c |
| `[^abc]` | 除 a、b、c 外的任意字符 |
| `[a-zA-Z]` | a 到 z 或 A 到 Z |
| `[a-d[m-p]]` | a 到 d 或 m 到 p（并集） |
| `[a-z&&[def]]` | d、e 或 f（交集） |
| `[a-z&&[^bc]]` | a 到 z 除 b、c 外（差集） |

---

## 五、预定义字符类（Predefined Character Classes）

| 写法 | 匹配 |
|------|------|
| `.` | 任意字符 |
| `\d` | 数字 `[0-9]` |
| `\D` | 非数字 `[^0-9]` |
| `\s` | 空白字符 `[ \t\n\x0B\f\r]` |
| `\S` | 非空白字符 |
| `\w` | 单词字符 `[a-zA-Z_0-9]` |
| `\W` | 非单词字符 |

---

## 六、量词（Quantifiers）

| 量词 | 含义 |
|------|------|
| `X?` | X，一次或零次 |
| `X*` | X，零次或多次 |
| `X+` | X，一次或多次 |
| `X{n}` | X，恰好 n 次 |
| `X{n,}` | X，至少 n 次 |
| `X{n,m}` | X，n 到 m 次 |

**三种量词模式**（回溯行为不同）：

| 模式 | 语法 | 行为 |
|------|------|------|
| **贪婪**（Greedy） | `X?` `X*` `X+` `X{n,m}` | 尽可能多匹配（默认），会回溯 |
| **懒惰**（Reluctant） | `X??` `X*?` `X+?` `X{n,m}?` | 尽可能少匹配 |
| **占有**（Possessive） | `X?+` `X*+` `X++` `X{n,m}+` | 占有多，不回溯（性能好但可能失配） |

**示例**（输入 `"foo"`，正则 `<.*>` vs `<.*?>`）：
- 贪婪 `<.*>` 会吞掉最多的内容
- 懒惰 `<.*?>` 会匹配最短片段

> **面试高频**：贪婪 vs 懒惰 vs 占有量词，以及**回溯（catastrophic backtracking）**可能导致正则失控、性能问题（如 `(a+)+$`）。

## 七、捕获组与边界匹配（Capturing Groups & Boundary Matchers）

### 边界匹配器

| 写法 | 匹配位置 |
|------|---------|
| `^` | 行首 |
| `$` | 行尾 |
| `\b` | 单词边界 |
| `\B` | 非单词边界 |
| `\A` | 输入开头 |
| `\z` | 输入结尾 |

### 捕获组（Capturing Groups）

用括号 `()` 分组，可通过索引访问子匹配，用于提取信息（如提取 URL 各部分）。

```java
Pattern p = Pattern.compile("(\\d{4})-(\\d{2})-(\\d{2})");
Matcher m = p.matcher("出生日期: 1990-05-20");
if (m.find()) {
    System.out.println("年: " + m.group(1));  // 1990
    System.out.println("月: " + m.group(2));  // 05
    System.out.println("日: " + m.group(3));  // 20
}
```

**非捕获组** `(?:...)` 用于分组但不捕获，可降低开销：

```java
Pattern p = Pattern.compile("(?:\\d{4})-(\\d{2})");
```

## 八、Matcher 方法（Matcher Methods）

| 方法 | 作用 |
|------|------|
| `matches()` | **整个输入**必须完全匹配（从头到尾） |
| `lookingAt()` | 从**输入开头**匹配（不需要到结尾） |
| `find()` | 在输入中**查找**任意位置的子串（可多次调用） |
| `group()` | 返回上一匹配的整个子串 |
| `group(n)` | 返回第 n 个捕获组 |
| `start()` / `end()` | 上一匹配的起止索引 |
| `replaceAll(replacement)` | 替换所有匹配 |
| `replaceFirst(replacement)` | 替换第一个匹配 |

```java
String text = "apple, banana, apple, cherry";
String replaced = text.replaceAll("apple", "fruit");
// "fruit, banana, fruit, cherry"
```

> **面试高频**：`String.matches(regex)` 等价于 `Pattern.matches(regex, input)`，它要求**整个字符串**匹配（内部是 `matches()`），因此常用 `.*` 包裹——这是新手常踩的坑。

## 九、性能与模式标志（Pattern Flags）

`Pattern.compile(regex, flags)` 可传标志：

| 标志 | 作用 |
|------|------|
| `Pattern.CASE_INSENSITIVE` | 忽略大小写 |
| `Pattern.MULTILINE` | `^` `$` 匹配每行首尾 |
| `Pattern.DOTALL` | `.` 匹配换行符 |
| `Pattern.COMMENTS` | 忽略空白和注释 |
| `Pattern.UNICODE_CASE` | Unicode 大小写 |

**性能建议**：重复使用的正则**务必预编译**为 `Pattern` 常量（`Pattern` 不可变、线程安全），避免每次调用 `Pattern.compile` 重复编译。**警惕灾难性回溯**。

## 十、常用实战示例

```java
// 邮箱校验
Pattern email = Pattern.compile("^[\\w.%+-]+@[\\w.-]+\\.[A-Za-z]{2,}$");

// 手机号（中国大陆，11位）
Pattern mobile = Pattern.compile("^1[3-9]\\d{9}$");

// 从日志提取 IP 和时间
Pattern logP = Pattern.compile("(\\d{1,3}(?:\\.\\d{1,3}){3}).*?(\\d{4}-\\d{2}-\\d{2} \\d{2}:\\d{2}:\\d{2})");
Matcher m = logP.matcher(logLine);
if (m.find()) {
    String ip = m.group(1);
    String time = m.group(2);
}

// 金额提取（非捕获组 + 贪婪）
Pattern money = Pattern.compile("￥(\\d+(?:\\.\\d{2})?)");
```

## 核心速查表

| 主题 | 要点 |
|------|------|
| 三大类 | `Pattern`(编译) / `Matcher`(匹配) / `PatternSyntaxException`(语法错) |
| 转义 | 正则 `\d` → Java 写 `"\\d"` |
| 字符类 | `[abc]` `[^abc]` `[a-z]` 及 `&&` 交集 |
| 预定义 | `\d`数字 `\w`单词 `\s`空白 `.`任意 |
| 量词 | `*` `+` `?` `{n,m}`；贪婪/懒惰`?`/占有`+` |
| 分组 | `()`捕获、`(?:)`非捕获、`group(n)` |
| 匹配方法 | `matches()`全匹配 / `find()`查找 / `lookingAt()`开头 |
| 替换 | `replaceAll()` / `replaceFirst()` |
| 性能 | 预编译 `Pattern`、警惕回溯、`CASE_INSENSITIVE` 等标志 |

> **后端实操**：参数校验（手机号/邮箱/身份证）、日志解析（IP/时间/栈帧提取）、配置文件解析、SQL 注入与 XSS 过滤的关键工具。务必预编译常量化。
