# 学习进度说明

!!! abstract "关于学习进度"
    这一页回答四个具体问题：进度存在哪、什么情况下会丢、怎么备份换机、阶段完成度到底怎么算。
    都是「遇到过才来找答案」的问题，可以直接跳到你关心的那一条。

!!! warning "先说最重要的一句：进度只在当前这一个浏览器里"
    本站没有账号系统，进度不会上传到任何服务器。**清缓存、换浏览器、换设备、用无痕模式，进度都不跟着你走。**
    如果你已经学了一段时间，请先花一分钟做一次[备份](#sec-backup)，再继续往下看。

---

## 一、进度到底保存在哪里 { #sec-where }

### 存储位置

进度保存在浏览器的 **localStorage** 里，键名是 `learning-progress-2.0`。它属于「浏览器本地存储」，不是 Cookie，也不是缓存文件——但因为绝大多数「清理工具」会连它一起清掉，实际风险和缓存差不多。

想亲眼看一眼自己的进度数据：按 `F12` 打开开发者工具 → `Application`（Firefox 是「存储」）→ 左侧 `Local Storage` → 选中本站域名 → 找到 `learning-progress-2.0`。

### 里面存了什么

```json
{
    "learned": {
        "基础理论/软件测试理论基础教程": true
    },
    "practice": {},
    "quiz": {
        "python-basics": {
            "score": 8,
            "total": 10,
            "percentage": 80,
            "completedAt": "2026-06-12T10:00:00.000Z"
        }
    },
    "labs": {
        "case-design-boundary": {
            "passed": 6,
            "total": 6,
            "title": "用例设计：边界与等价类",
            "completed": true,
            "lastAttemptAt": "2026-06-12T10:05:00.000Z"
        }
    },
    "lastUpdated": "2026-06-12T10:05:00.000Z"
}
```

| 字段 | 记的是什么 | 什么时候写入 |
|------|------------|--------------|
| `learned` | 教程是否标为已学习，键是教程 ID | 点教程页末尾的「标记为已学习」，或在线练习全通过时自动写入 |
| `quiz` | 每份测验的成绩（分数、总题数、正确率、完成时间） | 点测验页的「提交答案」后 |
| `labs` | 每道在线练习的最好成绩与完成状态 | 点练习框的「运行并判分」后 |
| `practice` | 结构预留位，当前页面不会往里写数据 | —— |

`practice` 是空的，不是坏了，也不是你哪里没做对——它只是历史遗留的字段。

## 二、什么情况下进度会丢 { #sec-loss }

这是新手最容易踩的一类问题：**不是进度没保存，而是根本没往你正在用的那个浏览器里存。** 按出现频率从高到低：

| 情况 | 会丢吗 | 原因 |
|------|--------|------|
| 无痕 / 隐私模式 | 关掉窗口就丢 | 无痕模式的 localStorage 在会话结束后清空 |
| 换浏览器 | 丢 | Chrome 的进度 Edge 读不到，反之亦然 |
| 换设备 / 换电脑 | 丢 | 数据没有离开过本机 |
| 清理「浏览器数据」勾选了「Cookie 及其他站点数据」 | 丢 | localStorage 就归在这一类里 |
| 清理「缓存」但没勾 Cookie/站点数据 | 不丢 | 缓存和 localStorage 是两回事 |
| 站点域名变了（换部署地址） | 丢 | 不同域名、不同路径都是独立的存储空间 |
| 手机换用 App 内置浏览器打开 | 丢 | 微信/QQ 内置浏览器与手机自带浏览器各自独立 |

!!! danger "一个高频误会：你以为在「保存进度」，其实换了个浏览器"
    很多人上班用公司电脑的 Chrome 学，回家用自己电脑的 Edge 看，然后发现「进度没了」。
    换机之前先看一眼[备份](#sec-backup)，比丢完再想办法省事得多。

## 三、怎么把进度备份下来 { #sec-backup }

### 手动备份（推荐，跨浏览器通用）

1. 打开[学习中心](../index.md)，截图总体进度条和五个阶段卡片。
2. 按 `F12` 打开开发者工具 → `Application` → `Local Storage`。
3. 找到 `learning-progress-2.0`，双击它的值，`Ctrl+A` 全选、`Ctrl+C` 复制。
4. 粘贴到一个 `.json` 文本文件里，和截图放在一起。

那一整段 JSON 就是你的全部进度。它不含任何个人信息，只有「哪些教程打了勾、哪份测验考了多少分」。

### 恢复（换浏览器 / 换设备后）

1. 在新的浏览器里打开本站任意一页。
2. `F12` → `Application` → `Local Storage` → 选中本站域名。
3. 如果还没有 `learning-progress-2.0` 这一项，先在控制台（`Console` 标签）执行一次：`localStorage.setItem('learning-progress-2.0', '{}')`。
4. 双击该键的值，把备份的 JSON 整段覆盖进去，回车。
5. 刷新页面，[学习中心](../index.md)的进度条应该回到备份时的状态。

!!! tip "恢复失败的三个常见原因"
    - 粘贴时被编辑器加了 BOM 或把换行删掉导致 JSON 不合法——恢复前先把内容粘到任意 JSON 校验工具里跑一遍。
    - 新环境是**无痕模式**，写进去刷新就没了。
    - 站点域名和原来不一致，导致你以为「恢复到同一个键了」，其实写在了另一个域下。

## 四、阶段完成度是怎么算的 { #sec-calc }

学习中心的进度不是「打勾数量 ÷ 教程数量」这么简单。每个阶段的完成度由三部分组成：

```text
阶段完成度 = （已学完教程数 + 已完成测验数 + 已通过练习数）
           ÷ （该阶段教程总数 + 测验总数 + 在线练习总数）
```

### 三种计入规则不一样

| 项目 | 计入条件 | 注意 |
|------|----------|------|
| 教程 | 点了「标记为已学习」，或该页的在线练习全部通过（自动标记） | 手动取消勾选会真的取消 |
| 测验 | **只要提交过一次就计入**，与分数无关 | 低于 80 分会在阶段详情里显示 `(XX分)`，但不影响是否计入 |
| 在线练习 | **必须全部断言通过**才算 | 只显示 `5/6` 这类部分通过的分数字样，但**不计入**完成度 |

因此会出现两种看起来矛盾、其实都正常的现象：

- **「我测验只考了 40 分，阶段进度却加了 1」** —— 是的，测验只统计「做没做」，考得好不好请自己按 80 分线复盘。
- **「我练习 5/6 差一题，进度没动」** —— 这是故意的。做了但没全对，记录在那里方便你下次接着改，但不算过关。

!!! tip "看到 100% 却没觉得学会？看这两个数"
    阶段卡片只显示一个百分比，但阶段详情里的 `(XX分)` 和 `⚠️ 5/6` 才是真实水平。
    进度条是「有没有走完流程」，不是「掌握程度」——后者请用[阶段学习检查清单](../阶段学习检查清单.md)自查。

## 五、如果你想清空重来 { #sec-reset }

- **只清掉某一项**：在学习中心取消对应勾选；测验和练习成绩没有单独删除入口，需要按下面的方式清理。
- **全部清空**：`F12` → `Application` → `Local Storage` → 删除 `learning-progress-2.0` → 刷新页面。
- **只清某一份测验的历史成绩**：控制台执行 `JSON.parse(localStorage.getItem('learning-progress-2.0'))` 查看结构，删除 `quiz` 里对应的键后写回；不确定结构的话，先按[备份](#sec-backup)存一份再动手。

清空前建议先导出备份——你不会想因为「想重刷一次」把整个阶段的记录一起清掉。

## 六、隐私说明 { #sec-privacy }

- 不收集个人信息，不需要注册登录。
- 不上传任何学习数据，本站没有后端账号系统。
- 不使用 Cookie 追踪行为。
- 你随时可以删除或改写这份数据，完全由本地浏览器控制。

## 七、遇到问题怎么办 { #sec-trouble }

1. 先对照[什么情况下进度会丢](#sec-loss)逐条排查，八成问题能在这里找到原因。
2. 确认是本站的功能问题（而不是浏览器设置或换机），到 [GitHub Issues](https://github.com/bingu7/test-tutorials/issues) 反馈，附上浏览器名称与版本、以及复现步骤。
