## 第一部分：测试岗位全景图

### 1.1 按"能力轴"分三类，不是按名字分

市面上的岗位名有几十种，但底层只有三条能力轴。搞清楚这个，你就不会再被岗位名迷惑：

```text
轴 A：业务质量轴  →  功能测试、业务测试、行业测试（金融/医疗/ERP）
      核心：懂业务 + 会设计用例 + 会定位问题
      门槛：业务理解 > 技术

轴 B：技术专项轴  →  接口、性能、安全、自动化、移动端、大数据
      核心：掌握某个技术领域的工具链和方法论
      门槛：技术深度 > 业务

轴 C：工程效能轴  →  测试开发、SDET、质量平台、DevOps 测试
      核心：写代码造工具，让测试本身变快
      门槛：编码能力 = 开发水平
```

**关键结论：轴 A 是入场券，轴 B 是涨薪点，轴 C 是天花板。** 你的教程对 A 和 B 覆盖很好，对 C 几乎是空白——这决定了你目前能拿 offer 的区间。
